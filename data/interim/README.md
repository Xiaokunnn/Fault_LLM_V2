# Intermediate Data

该目录包含页级解析、候选记录、模型响应、自动门控轨迹和术语治理实验。它们可能具有唯一审计价值，并非都能重新生成，因此不得整体删除。

- `parsed_pages/`：正文、表格、bbox、物理页、来源和页面哈希；
- `candidate_triples/`：候选、自动证据合格、隔离、拒绝记录及失败理由；
- `candidate_pages/`：历史页面计划和筛选清单；
- 真实API响应与裁决缓存：用于断点续跑、费用控制和复现，必须保留。

中间目录中的状态不能自动成为正式发布版本。尤其是1326条标准中文应用层目前仍位于术语治理实验目录；研究点三使用前必须另建显式、带哈希的教师图版本清单。
