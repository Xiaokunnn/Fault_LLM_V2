1. `contracts.py` 的 `else` 后再次 `elif` 导致模块无法导入；修复为非回答卡片的事实为空检查。

   改成保留实际池、张量宽度上限 32，显式掩码，不伪造补齐证据。
3. 增加不改变 K 的教师候选捕获、精确 K3 ID 比对、两阶段核验与缓存检查点。
   尾候选的辅助支持标签不能改变原 RP2 最终选择。
4. 修复 RP3 脚本直接调用时缺少仓库导入路径的问题。
5. 修复已有测试临时目录重复创建以及 CRLF/raw hash 与 normalized hash 混淆。
   RP2 冻结清单中的 13 项原资产字节仍被保留，未重算论文数字或改变上游教师。
6. 修复全掩码时 `finfo.min` 求和溢出再乘零产生 NaN 的风险。
7. 修复干预 trace ID 重用及 rollout ID 未包含模型/预测身份的问题。
8. 增加训练/在线一致的 CPU 哈希特征实现，解决“只接受预计算 query ID、不能处理新问题”的缺口。
9. 增加 MP008 逐字原文绑定校准候选生成与独立 trace/memory bundle，禁止进入梯度/早停。
10. 初始轨迹没有学生反事实表现时，屏蔽路由损失而不是制造成本标签。
    增加固定其余模块、仅拟合 route head 的教师相对效用训练入口。
11. 增加真实候选删除干预的 7B 重放和分组继承。
12. 增加实际 INT8 QDQ、量化后阈值拟合、经验风险/覆盖失败关闭、ONNX 输出评估入口。

## 研究价值仍需实验支撑

“LLM 调一个小工具”只是工程形式；研究结论应落在证据集合干预敏感性、主动欠填、
质量—回退率—计算开销的可验证关系上。40 个控制问题及其派生样本不足以单独支持广泛泛化结论。
哈希特征和单轮固定学生路由是可复現起点，不应包装成已经验证的最优模型或完整理论贡献。
