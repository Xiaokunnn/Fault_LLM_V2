# E1冻结语义特征可行性对照（2026-09-18）

本协议在新特征生成、训练与结果查看之前固定。它检验当前本地提案的质量空间，
本身不作为硕士论文算法创新。RP1/RP2、旧特征及全部既有实验只读保留。

## 对照与边界

- C0：复用已完成的requested_balanced三个种子，不重训。
- H512：原字符哈希算法扩至512维；证据仍附加完全相同的32维元数据。
- E1：冻结[BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)，
  revision `7999e1d3359715c523056ef9478215996d62a620`，全部模型/分词器文件绑定SHA256。
  CPU FP32、eval、CLS池化、L2归一化、512 token截断，batch16；查询按模型卡添加
  `为这个句子生成表示以用于检索相关文章：`，证据不加前缀。无微调，无语料统计拟合。

H512/E1均query512、evidence544、hidden384，控制器参数/初始化/优化器完全配对。
C0→H512识别维度改变，H512→E1识别固定表示方案整体改变（包含标准查询前缀），
不能细分前缀和预训练权重各自的贡献。三种子7042027/7042028/7042029；其余配置继承C0：
requested_balanced、rank/support=1、field/cardinality=.6、其他损失=0，
batch16、LR.0003、weight_decay.0001、clip1、最多30epoch、patience5、validation总损失早停。
不叠加S1/G1/W1/J1，不改支持阈值.5。编码器全部参数计入50M上限。

查询文本只含question_zh、fault_name_zh、requested_role；证据文本只含head_label_zh、relation、
tail_label_zh、evidence_text。元数据仅role、fault_class_ids、evidence_contract_confidence。
trace ID只作特征索引，不进入编码；派生查询共享文本编码，干预由可用性mask表达。
冻结记忆的证据属于已声明fixed_memory_query_generalization，不能称证据文档未见泛化。
只读构建集129/36条（原始32/8，独立场景8/2），不读取MP008、MP009–MP013作实验判断。

## 预先固定判据

主要单位为原始validation的场景宏平均，再对三个种子平均；派生/全部与train分别报告。
完整输出非空标签预测零比例、原始/约束解码请求字段数量准确率、Pointer P/R/F1，
支持正召回、负支持误接受、AUC/AP/Brier，以及教师空集/困难空集/无候选误填。

E1须同时相对H512和C0满足：F1严格提高、正支持召回不降、非空最终为空比例不升、
解码数量准确率不降、负支持误接受不升；每种子完整val教师空集误填不升、无候选误填和契约违规为0。
固定本地非空精确提案数G须种子均值严格提高且每种子不下降。
所有条件均为内部可行性门槛，非显著性检验、独立泛化或风险认证。
若不通过，停止本轮语义模型搜索；保留正负结果，不事后换seed、阈值、encoder或早停指标。

## 成本与理论边界

预先选7042027测成本（不按分数挑选）。各臂独立进程，CPU FP32、单线程、5次预热，
对40条原始构建查询每条重复30次，实测查询编码、缓存证据组装、控制器前向和约束解码。
语义查询每次重新编码；证据离线缓存，另报缓存/权重字节数、完整参数与进程RSS。
不计文件加载、网络、渲染、LLM外壳及教师回退；这是服务器CPU组件成本，不是完整系统或目标边缘设备时延。
相同后端重新测C0只属只读计时，不重新训练基线。

设固定教师非空数P、正确非空本地提案G、查询数N、同质完整教师回退成本T，
每查询都先支付本地成本c。理想oracle零错误且服务全部非空任务的最低平均成本为
`c + T(P−G)/N`：每次回退至多修复一条，oracle恰可回退全部P−G条。
两个oracle的成本差为`Δc − TΔG/N`。若ΔG>0，要获得严格净节省必须且只须
`T > NΔc/ΔG`（在此理想同质模型内）；若ΔG≤0且Δc>0，新方法在此oracle比较中劣于控制。
实测逐查询成本用样本平均c代入；两策略都先支付全部本地成本。
这不是实际路由间成本差的界：两个实际策略的错误拒绝、误接受和错误回退损失可以不同。
也不涵盖跳过编码直接回退的策略或异质教师成本，不能由此证明真实部署有效/无效。

若质量与成本空间成立，下一步才预注册训练组交叉拟合的资源条件化选择性执行；
否则暂停其有效性主张。语义相似性不是证据蕴含证明，教师一致性不是专家诊断准确率。
当前MP008无有效校准证书的状态不会因本实验改变。
