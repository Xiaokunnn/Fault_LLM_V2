## 唯一架构因素

沿用查询—候选编码`h_i∈R^384`，可用集合A、固定候选槽数M=32，`m=|A|`。
S1使用`μ=Σ_{j∈A}h_j/max(1,m)`及`a=(m/M,log(1+m)/log(1+M),1[m>0])`。
候选支持logit为

```text
s_i = wᵀh_i+b + ρ([h_i, μ, h_i⊙μ, |h_i−μ|, a])
ρ = Linear(1539,96) → LayerNorm(96) → GELU → Linear(96,1)
```

S0对每个可用候选使用`μ=h_i,m=1`，不观察其他候选；其余结构完全相同。
不可用位置内部置零，最终沿用原有限最小值掩码。残差不增加dropout，不更改排序、字段或Route前向公式；
共享编码器会接收新的支持梯度，因此训练后的其他头允许间接变化，不能声称它们被冻结。
残差最后一层权重/偏置为零；所有原参数与C0同种子初始化逐元素相同。
分支初始化包在独立RNG上下文内，不消耗原模型后续dropout随机流。
S0/S1参数量相同；训练前记录精确数量，均必须<50M。容量收益需与上下文收益分开解释。

## 可证明性质和限制

1. eval模式下候选重排只重排`h_i`，均值/数量不变，共享ρ使支持logit排列等变。
2. 固定槽数和可用性掩码时，修改不可用候选的有限特征不影响可用支持输出；全空最终不能输出answer/非零基数。
3. 对保留候选i删除另一个候选j、m>1，有`μ'−μ=(μ−h_j)/(m−1)`。
   若`||h_j||₂≤B`，则`||Δμ||₂≤2B/(m−1)`。若ρ在所考虑区域内为L-Lipschitz，
   支持变化满足`|Δs_i|≤L sqrt((2+B²)||Δμ||₂²+||Δa||₂²)`。
   这是固定参数下的条件敏感性界；L/B未被训练约束，不是数值认证或删除后必然降低支持的保证。
4. 集合均值不是任意集合的单射；即使本数据冲突输入被区分，也不能证明教师标签正确或外部泛化。

集合不变/等变建模已有[Zaheer等Deep Sets，NeurIPS 2017](https://papers.neurips.cc/paper_files/paper/2017/hash/f22e4747da1aa27e363d86d40ff442fe-Abstract.html)。
本实验不把池化架构本身作为原创，也不把观测上下文自动解释为现实故障因果关系。

## 执行前判定与停止规则

分别比较S1/C0、S1/S0。两组都必须满足下列条件，才认为上下文改动通过本轮内部比较：

- 原始validation场景宏三种子均值Pointer F1严格提高；正支持召回不降低；
  非空目标最终为空率不升高；请求decoded基数准确率不降低。
- 原始validation场景宏三种子均值负支持误接受率不升高，避免复制G1的正负概率一起抬高。
- 每个种子完整validation教师空集误填不增加，无可用候选误填为0，输出契约违规为0。

另报告raw非空零预测、raw基数准确率、Pointer P/R/F1、支持AUC/AP/Brier、
困难空集误填及场景结果；均值改善不等于每个种子改善。仅2个validation场景，不作显著泛化宣称。
规则不通过则保留负结果，停止本条架构/损失试探；不调残差宽度、权重或换种子再试。
按照用户允许调整研究点的授权，转入RP3范围与可行性评审，优先评估风险约束的选择性核验/边云协同，
冻结RP1/RP2及原始失败结果，不通过改名把既有失败变成成功。
