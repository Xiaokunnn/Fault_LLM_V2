# RP3 正支持参数更新保护 v1：执行前固定协议

## 审计与本轮问题

C0三个checkpoint的全训练集eval-mode梯度中，正支持与困难负例方向余弦为−0.7242/−0.8266/−0.8018，
0.25倍困难负例梯度范数是基础梯度的2.4122/2.1985/2.3819倍。
按这三个点的普通梯度方向计算，追加负例项会局部增加正支持损失。
这不是实际历史AdamW轨迹，也不证明唯一根因；但为保留正支持的更新约束提供了可检验动机。

另有观测问题：点式支持头不读取其他候选的增删，train 199组输入中10组存在相反教师标签，
validation 36组中3组冲突；已保存模型对同输入输出完全相同。
其经验最少错误分别为10/756、3/126。训练中的5条困难空集均不属于这些冲突组，
故不能把困难负例导致的覆盖下降全部归因于输入别名。上下文条件化另立实验，本轮不改模型。
教师标签变化也可能包含核验器变异，不据完整上下文可区分就认定标签因果正确。

## 目标与更新规则

复用W1标量目标`L_W=L_base+0.25 L_H`，不加入联合语义正则，不改变数据、特征、架构、解码或Route。
定义构建**train**中全部已核验、可用且请求角色匹配的正支持出现项集合P：

```text
L_+(θ) = mean[(x,i)∈P] softplus(-s_i(θ,x))
```

每个minibatch仍按W1进行反向、原有梯度裁剪及AdamW更新。设优化器提出实际参数位移d，
在更新前参数θ、eval模式、全train正支持上求g=∇L_+(θ)。不使用validation梯度或MP008。
保护的是包含Adam预条件、动量和weight decay后的**实际位移**，不把普通梯度投影的结论直接套到AdamW。
当||g||、||d||均非零，固定ρ=0.1，求：

```text
min_v 0.5 ||v-d||²  subject to  gᵀv ≤ -ρ ||g|| ||d||
v = d - max(gᵀd + ρ||g||||d||, 0) / ||g||² × g
```

这是单个半空间的欧氏投影，公式来自KKT条件；ρ仅为预声明常量，不宣称最优。
g=0或d=0时保留原提案，然后仍检查实际正支持损失。
依次尝试α=1,1/2,…,1/256，接受首个满足
`L_+(θ+αv) ≤ L_+(θ)+1e-7`的有限结果。1e-7仅为FP32容差，不是允许调大的风险预算。
若9次都失败，则恢复参数和更新前完整AdamW状态；不删除失败记录。
若接受投影/缩短的参数步，保留此次AdamW产生的矩状态，明确属于带保护的更新算法，不能声称等价于标准AdamW。
每次保存步长、投影量、方向内积、正支持前后损失、拒绝/回溯次数和时间；不保存额外checkpoint用于事后选模型。

若L_+局部梯度Lipschitz，g非零时严格负的方向导数保证足够小的步长能下降；
有限回溯不保证找到该步长，故实现保留拒绝回退。接受检查只给出本次全train平均正支持CE的数值非增条件，
不保证单条正例、validation召回、总体目标或最终Pointer F1单调改善。
固定0.5支持门槛下，每个正例被拒绝时其CE≥log2，故经验FN比例≤L_+/log2；
这是代理上界，降低该上界不等于实际FN比例必然下降，更不是外部安全证书。
梯度冲突处理已有研究，如[Yu等，NeurIPS 2020](https://arxiv.org/abs/2001.06782)；
本轮不是复现PCGrad，也不宣称半空间投影或回溯搜索是原创。

- G1使用7042027/7042028/7042029三个种子，从相同种子初始化训练，独立目录`positive_guard_v1/seed_*/G1`。

- 不使用MP008/外部样本，不重跑teacher/features/旧学生，不调整0.5支持阈值，不量化/校准/部署。
