# E1语义特征可行性对照结果：2026-09-18

**E1相对历史C0和同维度H512的预声明整体改善条件均失败。**
语义编码减少了部分欠填，但Pointer F1下降、一个种子误填增加，且未扩大相对C0的正确本地提案空间。
编码器全成本计入后，组件推理明显变慢。按预设停止本轮encoder搜索，暂不训练依赖其改善的新路由。
这是当前教师、表示、控制器和数据协议下的内部负结果，不是“小模型或语义编码普遍无效”的结论。

## 早停与正确性

H512三个最佳epoch均1，E1为2/1/1；总训练epoch为H512 6/6/6、E1 7/6/6。
E1从最佳到末epoch，validation排序损失增加1.0744/0.8812/1.2567；
字段和数量损失下降仍被抵消，总损失增加1.0702/0.6443/0.8968。
早期最佳现象未因语义特征消失。这定位了总损失的数值变化，尚未证明唯一因果机制；
不能事后换为Pointer F1早停并沿用本轮结果作为新方法成绩。

- 141项RP3测试通过，10条已有ONNX tracer warnings。
- 教师/划分/标签/可用性mask/32维元数据一致，模型/源码/特征及checkpoint绑定通过核验。
- 九个新旧模型全部epoch的目标重建最大误差<2.6e-7，最佳epoch均为validation总损失最小值。
- 改动不可用位置特征不影响任何输出头；40条原始查询线上重算特征与离线缓存最大误差为0，选集一致。
- 1457个既有研究与日志文件逐文件SHA256未变。
- 首次独立审计因C0旧清单没有显式保存默认`support_context=pointwise`而停止；补齐默认值比较后通过。

## 全成本与理论可行性

同一Xeon Silver 4210R服务器、PyTorch CPU FP32单线程；预先固定seed7042027，
每条原始构建查询5次预热、30次计时。每次重新编码查询、访问证据缓存、执行LEC和约束解码。
下表为8条原始validation组件成本，p50/p95取其240次测量。
不含磁盘加载、网络、渲染、LLM外壳或教师回退，不能写成端到端或目标边缘硬件结果。

| 臂 | 总参数 | FP32参数MiB | 均值ms | p50 / p95 ms | 补测整进程峰值MiB |
|---|---:|---:|---:|---:|---:|
| C0 | 1,261,093 | 4.811 | 4.812 | 4.370 / 5.646 | 419.6 |
| H512 | 1,457,701 | 5.561 | 5.357 | 4.950 / 6.049 | 426.3 |
| E1 | 25,411,621 | 96.938 | 82.342 | 81.512 / 87.541 | 728.8 |

E1查询编码单项均值76.855 ms。静态证据FP32向量为C0 239,616字节、H512/E1 452,608字节。
证据记忆本身很小，不能以“图太大无法放边缘”为研究动机。

原计时子进程`ru_maxrss`三臂同为887,524 KiB，受到历史高水位影响，无法比较模型增量。
保留原数据，另在新进程用`/proc/self/status`逐阶段补测，上表使用补测HWM。
内存包括解释器、库、语料与特征表，不是纯模型占用；补测只读前向，没有重训或改写原计时。

理论审查使用固定提案oracle必要条件。原始val有P=7个非空任务，E1的G=2/1/0，
即使oracle也至少需要5/6/7次完整教师回退；C0只需5/5/7次。
在两策略每查询先付本地成本、完整教师成本同质为T时，oracle平均成本差为

```text
ΔC_oracle = Δc − TΔG/N
```

E1/C0三个种子的ΔG均≤0，验证平均Δc=77.530 ms，因此E1没有取得更好的oracle成本前沿。
E1/H512只有seed7042027增加1条正确提案，理想同质模型的净节省要求T>615.885 ms；
另两种子未增加正确提案。不能挑该种子或假设实际教师成本后宣称已有系统收益。

这是两个理想oracle之间的比较，不是未知真实路由策略成本差的界。
跳过本地计算、异质教师成本和风险估计误差不在等式假设内。
简单界和编码器替换是可行性审查工具，不是原创算法贡献，也不提供风险证书。
原始记录见[`cost_feasibility.json`](../results/experiments/research_point_3/semantic_v1/cost_feasibility.json)。

## 对硕士研究点的影响与下一步

当前证据不足以支持“完整四头蒸馏有效”或“切换到学习型路由即可有效”。
理论公式正确和方法客观有用是两个门槛：本轮给出可核查条件与反例，但未取得整体任务/资源收益。
不能将负结果更名为创新，或因完成很多实验便认为硕士研究点成立。

下一步先做**任务—监督—评价协议评审**，再决定是否恢复算法实验：

1. 只读构建集审查教师排序、二元支持与最终选集目标是否一致，以及单角色任务的可观测信息边界。
   区分可证伪原因与事后解释，不重跑旧教师或修改其标签。
2. 如需新监督，先制定独立构建场景/查询族协议，只来自15篇构建文档，使用冻结教师生成另版本记录。
   改写/派生行不算新增独立组，不使用MP008或外部集补训练。本轮没有开始生成新监督。
3. 固定提案具备足够正确非空答案后，才考虑训练组交叉拟合的资源条件化风险/回退价值学习。
   提前定义成本、覆盖、风险、不可行动作及始终本地/教师/拒答控制，明确与RP2证据选择的区别。
4. MP008现有3条非空与最低5接受/最高10%不一致约束的不可行性不变；校准问题单独评审，
   不降低门槛，不凭新研究名称使旧证书有效。无可行数据/评估设计时继续暂停学习型有效性主张。

这是有停止条件的研究范围复核，不是已完成的新算法或新的部署许可。
