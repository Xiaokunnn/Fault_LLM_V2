## 3. 上下文是否实际生效

独立复核保存checkpoint：每个S1种子在train的10个、validation的3个旧点式冲突组都产生大于1e-6的logit差异；
C0/S0所有这些组的差异为0。可见新分支不是未接入或未加载。

| seed | S1 train冲突组最大logit差 | S1 validation冲突组最大logit差 | S1相对C0改变选集 train/val |
|---|---:|---:|---:|
| 7042027 | 0.0050590 | 0.0083152 | 8/0 |
| 7042028 | 0.0003873 | 0.0005840 | 7/0 |
| 7042029 | 0.0011457 | 0.0015143 | 0/0 |

候选反向排列的最大支持logit误差1.20e-7；改变不可用候选特征不影响可用支持分数。
排列等变、屏蔽和条件删除敏感性界见预注册协议。
“能感知变化”没有转化为本轮validation的选择质量收益；不能把可辨识性当成学会正确判别。

## 4. 早停与成本

最佳epoch仍2/1/1。S1从选中epoch到最后epoch的validation总损失为
2.5221→3.4683、2.5098→3.0428、2.4489→2.9555；ranking loss为
1.3110→2.0706、1.1196→1.9333、1.0883→1.8956。
保留原选择规则，没有按后期F1另选checkpoint。

六次训练子进程耗时约8.01–8.76秒，包含进程启动、输入核验和保存开销，不能当作边缘推理耗时。
本轮没有新ONNX/INT8，也没有新部署证书。后续若保留该架构，仍需单独量化后校准。

回退预算b最多服务`min(P,G+b)`条非空任务，完整服务至少需要`P−G`次完整教师回退。
已用合成样本枚举全部三动作策略核验。Oracle读取教师标签，不能当作实际路由器成绩。

仅改路由无法改变这个提案质量上限；同一批数据没有证明四头整体蒸馏或纯路由替代已成功。
按照用户允许调整研究点的授权，暂停当前哈希特征四头优化链，将下一阶段收窄为
