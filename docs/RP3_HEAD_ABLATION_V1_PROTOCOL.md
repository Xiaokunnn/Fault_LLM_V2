# RP3 逐头消融 v1 预声明协议

日期：2026-09-17。执行前固定本协议及 `configs/research_point_3/head_ablation_v1.json`。

## 问题与范围

在同一构建集、字符哈希特征、组隔离和优化设置下，比较排序、支持、字段欠填、代价路由的贡献。
仅训练/诊断构建集；不读取MP008样本、不校准、不读取MP009–MP013、不部署。
本轮是内部消融，不替代B0/M0主对照，也不改变两组失败结果。

## 固定设计

- 数据：已冻结的40原始+125证据移除轨迹；129 train、36 validation，只有10个基础故障场景。
- 新种子：7042027、7042028、7042029，全部报告，不按结果挑选种子。
- 编码器、四头容器、hidden=384、batch=16、lr=0.0003、30 epochs、patience=5等沿用M0。
- 不删物理头以保持共享模型容量；未启用头不参与损失或相应解码，参数量仍计入全部容器。
- 三个学习臂都令额外intervention项和calibration Brier项权重为0，避免复合辅助损失向被消融头泄漏监督。
  派生样本仍参加各启用头的普通监督。该控制与M0的复合目标不同，不能把A4写成M0复跑。
- 每臂均以自身预声明损失在build-validation上早停；不使用MP008或外部指标。跨臂不比较loss数值大小。

| 臂 | bootstrap损失 | 解码/路由 |
|---|---|---|
| A1 | rank=1；其余=0 | 可用、已知、所需角色内rank top≤3；没有支持门控，仅作内部危险接受对照 |
| A2 | rank=1、support=1；其余=0 | 同A1并加support≥0.5；不使用字段/数量头 |
| A3 | rank=1、support=1、field=0.6、cardinality=0.6；其余=0 | 完整字段/数量解码；非空提案本地回答，空提案弃答 |
| A4 | 直接复用同种子A3 bootstrap，冻结非Route参数，只拟合Route | 沿用现有cost-sensitive route拟合，成本1/8/12/50，最多100 epochs、patience=10；完整解码 |

A3与A4共用bootstrap，避免重复训练；A4的Route目标仅使用当前学生与冻结教师的构建集rollout。
当前Route拟合器无采样、关闭dropout，沿用原确定性实现；三种子差异来自各bootstrap初始化和训练。
所有臂都强制未知ID、不可用ID、角色和预算边界。A1的非空提案不代表通过二值支持契约，禁止作为生产回答。
支持、字段、Route的原始质量指标只对启用并训练过的头解释。

## 产物与统计

输出根目录：`results/experiments/research_point_3/head_ablation_v1/`。
每个种子下A1/A2/A3各有独立bootstrap，A4保存独立routed checkpoint和rollout。
三种子全部保存config、checkpoint、训练历史、原始推理诊断和汇总。

主表单列原始32/8条train/validation；派生97/28条及合并结果另列。
报告各种子的非空集合成功数、含空集一致率、Pointer P/R/F1、NDCG及场景级均值。
按基础场景聚合，报告三个种子的均值、样本标准差、最小/最大和95% t区间（df=2，描述性区间，不作显著性结论）；
同一数据仅重复三个训练种子，不能作为外部泛化保证，区间可以超出[0,1]且不裁剪。
失败种子和运行错误单独保留；不重跑选优。不得将派生条目当成独立病例计算显著性。

## 停止与后续

先执行语义/身份/边界测试，再运行实验。任一臂出现输入哈希不符或非有限loss时停止并保留产物。
结果差不能成为放宽门槛、重分组或修改现有三种子协议的理由。
去可用性观测、去派生监督及E1语义特征属于后续独立对照，不以本轮逐头消融冒充完成。
