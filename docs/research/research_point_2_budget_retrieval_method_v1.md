# 研究点二：来源族感知的预算约束低时延图谱证据检索

- 版本：`marine_pump_rp2_budget_retrieval_v1@1.0.0`
- 输入：研究点一冻结的 `KG_v1_validated`
- 数据政策：仅 Silver，绝不称 Gold；无领域专家审核
- 协议状态：已于 2026-08-01 在首次解析 MP010–MP013 前冻结

## 1. 研究边界

研究点一解决“知识如何可追溯、可审计地进入中文证据图谱”；研究点二解决“在给定查询和在线成本上限时，如何快速取得高价值、低冗余且来源多样的证据”。

本研究不修改图谱中的 Silver 决策，不用检索结果回填主图，也不把缩短 Prompt 或减少 Token 作为主要优化目标。

## 2. 问题定义

将可追溯证据图谱写为：

\[
\mathcal G=(\mathcal V,\mathcal C,\mathcal A,\mathcal P),
\]

其中 \(\mathcal V\) 是规范实体，\(\mathcal C\) 是语义 Claim，\(\mathcal A\) 是 EvidenceAssertion，\(\mathcal P\) 是文档、页码、URL、哈希和来源族等谱系元数据。给定结构化查询 \(q\) 和候选证据集 \(E_q\)，选择子集 \(S\subseteq E_q\)。

在线成本不由 Token 唯一代理，而是分解为：

\[
C(S,q)=\alpha N_{anchor}+\beta N_{claim}+\gamma N_{score}
      +\delta N_{evidence}+\eta T_{serialize},
\]

其中 \(N_{anchor}\)、\(N_{claim}\)、\(N_{score}\) 和 \(N_{evidence}\) 分别表示锚点、Claim 扩展、候选评分和证据访问数。实验直接记录这些计数及端到端时延，不在得到结果后用主观权重换算为单一“算力分数”。

## 3. 来源族感知预算选择

对候选证据 \(e\) 定义查询相关性 \(r(e,q)\)、结构合法性 \(m(e,q)\)、证据置信 \(c(e)\)和访问代价 \(d(e)\)。对已选集合 \(S\)，使用边际增益：

\[
\Delta(e\mid S,q)=w_r r(e,q)+w_m m(e,q)+w_c c(e)
 +w_f\mathbf 1[f(e)\notin F(S)]
 -w_o\max_{s\in S}\operatorname{overlap}(e,s)-w_d d(e).
\]

\(f(e)\) 是发布者谱系归并得到的来源族。新来源族奖励用于抑制同一厂商多份手册重复占据预算，但不意味不同来源族在统计上独立。

预算约束为：

\[
N_{score}\le B_s,\qquad |S|\le K,\qquad
|S_f|\le K_f,\qquad T(q)\le B_t.
\]

在候选耗尽、最佳边际增益低于冻结阈值、证据数达到 \(K\) 或截止时间 \(B_t\) 到达时提前终止。返回结果必须标记 `complete / partial / timeout`，不允许在评价时删除空结果或超时查询。

## 4. 防泄漏约束

- CQ 的 `fault_class_ids`、答案实体 ID、相关证据 ID 及 relevance grade 只作为隐藏评价字段。
- 在线方法只读取查询文本、实体标签/原词、显式类型、关系、证据置信、来源族和离线索引。
- 开发版 CQ 候选集用于程序联调、消融和参数选择，不是外部泛化证据。
- MP009 只能作为非盲迁移组；MP010–MP013 在本方法、索引、预算、基线和指标冻结前不解析。

## 5. 对照与实验

最小对照包括：

1. 词法全扫描；
2. 合法关系角色门控后的相关性 Top-K；
3. 倒排锚点与元路径门控后的 Top-K；
4. 旧原型的固定跳数扩散；
5. 旧原型的自适应能量剪枝；
6. 来源族感知预算约束方法（Ours）。

主指标为 Recall@K、MRR、nDCG、来源族覆盖、精确Claim冗余、p50/p95、超时率、完成率和候选访问数。必须给出预算—质量—时延 Pareto 曲线，不能只报单一预算点。

消融包括：去掉倒排索引、去掉关系角色门控、去掉来源族奖励/封顶、去掉冗余惩罚、去掉提前终止。敏感性至少覆盖 \(B_s\)、\(K\)、\(K_f\) 和截止时间。

## 6. 当前开发结果边界

开发版基准从冻结 CQ v1 和 `KG_v1_validated` 派生，共40问、208条候选证据，其中34问有 Silver 相关证据，6问标为图中无可回答结构。该数据只支持开发阶段的可运行性和质量—时延趋势，不支持外部泛化或真实诊断正确率结论。

当前 Ours 相对词法全扫描减少了候选评分和 p95 时延，并提高来源族覆盖、降低精确Claim冗余；但在当前单预算点上 Recall@budget 低于不做来源封顶的元路径Top-K。这是待通过Pareto、自适应封顶和保留集评价验证的权衡，不得改写为“Ours全面最优”。

## 7. 冻结参数与开发集结论

固定 `K=4`、最大评分候选数 32。参数选择不使用主观加权总分，而采用预先声明的约束式规则：先保留 Pareto 非支配解，再要求 Recall@4 不低于元路径 Top-K 的 Recall@4 减 0.01，最后依次最大化来源族覆盖、最小化精确 Claim 冗余和 p95 时延。冻结参数为来源族奖励 0.12、冗余惩罚 0.32、单来源族最多 3 条。

开发集上，冻结配置的 Recall@4 为 0.4721，平均来源族覆盖为 3.5，精确 Claim 冗余为 0，p95 为 1.33 ms。元路径 Top-K 的对应数值为 0.4698、2.5、0.0368 和 1.24 ms。固定两跳和旧自适应能量剪枝的 Recall@4 分别为 0.2619 与 0.3195，说明直接扩散在当前证据图上引入了较多无关访问。上述结论仅限开发集，不代表外部泛化性能。
