## 先排除“换成路由就能成功”的假设

只读可行性审计：[`scope_feasibility_v1/audit.md`](../../results/experiments/research_point_3/scope_feasibility_v1/audit.md)。
令P为教师非空任务数，G为固定本地提案中契约通过且集合完全一致的非空数，b为完整教师回退预算。
理想oracle允许免费选择正确本地答案、正确弃答教师空集，以及回退剩余任务，则

```text
零错误非空服务数 ≤ min(P, G+b)
完整非空服务需要 b ≥ P−G
```

证明：无需教师即能正确服务的任务至多G个，每一次完整教师回退最多新增一个正确服务任务。
Oracle选择所有G个本地正确项，再回退其余b个非空项即达到此界；这是有限数据上的可达上界。
真实策略不知道哪些本地答案正确，因此可能更差，不能把oracle用于在线接受或校准。

原始validation的P=7，B0的G=1；C0/S1三种子的G=2/2/0，全覆盖至少回退5/5/7次。
A2在不同解码条件下G=2/3/2，仅作乐观参考，仍至少回退5/4/5次。
所以当前不能直接宣称“只学一个路由头”足以显著节省教师计算。
计量单位是完整RP2教师回退，不等于单条7B核验调用次数、实际时间或能耗。

## 候选问题与RP2的区别

RP2仍回答固定证据池中“在给定预算下选择哪些证据并核验”，候选选择/核验规则及论文结论冻结。
调整后的RP3拟回答：在固定本地提案和可观测设备/网络状态下，何时本地执行、何时完整回退、何时拒答，
才能在明示服务覆盖与教师相对风险约束下节省端到端资源。
新实验必须引入资源状态、端到端计量及动作可行性；若仅重做RP2的候选预算扫描，不能作为独立研究点。

本地提案生成器必须预先固定，不能根据路由validation挑seed或更换为其oracle最优提案。
字段/数量可作为已有对照继续保存；若改为规则字段闭包，须另立协议，明确它放弃了哪些学习目标。
“合同有效”仍只表示可执行证据契约成立，不代表事实正确或工程安全。

## 候选理论主线

对状态z（查询、可用证据、本地提案、可测资源状态）及三动作a定义：

- C(a,z)：事先声明或实测的端到端资源成本；未测量时明确标为仿真成本。
- D(a,z)：返回非空答案但与冻结教师集合不一致的指示量。
- A(a,z)：是否返回非空答案；H(z)：教师是否非空。
- U(a,z)：教师非空却未返回非空答案的未服务指示量；错误非空回答由D约束。

研究候选为

```text
min_π E[C(π(z),z)]
subject to E[D] ≤ ε E[A], E[A] > 0,
           E[U] ≤ δ E[H],
           π(z) 属于设备/网络/时限下实际可行动作集合。
```

同时报告答案精确性、局部和系统覆盖；不能通过全部弃答降低表观风险，也不能用全量教师回退冒充成本节省。
固定非负乘子λ、μ时，拉格朗日动作分数为
`E[C+λ(D−εA)+μ(U−δH)|z,a]`；在动作可行集合内最小化估计分数。
若所有动作分数估计误差≤η，则所选动作对该固定拉格朗日分数的逐状态后悔≤2η，
由在真实/估计最优动作间各插入一次误差界直接得到。
这不保证原约束可行、不证明学到真实η，也不能代替独立校准或有限样本风险证书。
若资源预算不足以达到`P−G`的oracle必要条件，必须显式暴露不可行性，而非只调损失权重。

选择性预测/回退与代价敏感学习已有
[Mozannar与Sontag，ICML 2020](https://proceedings.mlr.press/v119/mozannar20b.html)，
回退概率校准的局限已有[Verma与Nalisnick，ICML 2022](https://proceedings.mlr.press/v162/verma22c.html)。
这里使用冻结教师相对目标，不能套用文献中的专家正确性结论；通用三动作路由、拉格朗日方法和2η界本身均非原创。
硕士课题的方法贡献仍需落在本任务的契约闭包、可行性约束、资源条件化风险建模和完整实验验证上。

## 下一阶段按门槛推进

1. **先验证本地提案是否值得继续压缩。** 预注册一个E1冻结中文语义特征候选及相同哈希控制，
   总参数/内存/编码时延计入边缘成本；只用构建集。固定模型与三个种子后检查支持可分性、
   教师非空精确提案数、误填及oracle回退下界，不再同时叠加S1/G1或改早停。
   该步骤后于2026-09-18完成，E1相对C0/H512的总体判据均失败；详见下方续记。
2. **存在足够提案质量空间后才学习选择性执行。** 在训练组内做预声明的分组交叉拟合，
   避免用生成器对自己训练样本的过乐观成绩当作校准证据；保持组隔离validation。
   预声明always-local、always-teacher、always-abstain、固定置信度及资源无关路由控制。
3. **风险认证与数据可行性单独处理。** MP008原40条、3条非空以及5答案/10%门槛全部保留。
   若以后提出新的校准任务或数据，只能另立协议和独立记录，说明改变了什么；当前证书不会因此自动有效。
   不把MP008用于表示/模型选择，不借MP009–MP013扩充训练或校准。
4. **系统收益必须实测。** 固定提案、路由与门槛后再量化和重校准，测编码、证据访问、渲染、网络及完整教师回退。
   没有目标边缘硬件只能报告资源受限仿真。

如E1或新的构建集设计仍缺乏可利用的正确提案、组隔离评估或可行校准条件，暂停“学习型风险路由已有效”的主张，
继续以可审计原型、可行性边界和负结果呈现。不能凭改题名保证硕士创新点已成立，也不能把单纯部署工程当已验证算法贡献。
