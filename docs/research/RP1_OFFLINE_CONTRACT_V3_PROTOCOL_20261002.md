## 1. 本轮可以裁定什么

下列是明确、可复查的**研究任务操作约定**，由本助手依据源文作技术裁定，并非独立领域专家意见。原 v2/v2.1 文件不变，所有参考变更另存 overlay。专家队列继续空白，不冒填专家身份。

1. `maintained_by` 表示保养、修复、检修拆装步骤；单纯启动、灌液、运行调节或恢复运行的操作进入 `operating_procedure` 旁路。启动前的真实检查仍可为 `inspected_by`，但操作本身不因此成为维护。检修拆装需保存章节、步骤编号、适用轴承架/材料、前提及外部子程序/力矩引用；单个步骤不得作为完整作业指令。
2. 泵专用手册中明确的部件维护章节可以继承**该手册泵型的限定适用范围**。MP018 轴承表进入 primary 的“可迁移泵部件知识”层，保留非船舶专用、泵型与服务范围；不升级成船舶现场验证事实。MP002 通用可靠性指南没有这种局部应用链，仍为 background。另报 MP018 内容已经抽到却被分入 background 的数量，不能把范围改判全部称为新抽取。
3. `no maintenance required` 保存为 `maintenance_requirement`：`requirement=not_required`、`action=maintenance`、`modality=not_required`。它不等于禁止维护，更不等于正向维护。“不得拆/调”则是 `prohibited`；“适度变色不足以报废”是负向报废依据。旁路要求不扩充冻结 15 类关系，也不混入核心正向边数。
4. 条件可存于端点、条件字段或 applicability 中；仅藏在引用内不算已结构化保留。if/whether 检查项不当作条件前提；OR 不改 AND；表头 PROBABLE CAUSE 仅约束原因列，不能传播到表现列。负向例外附到对应规则，不传播到无关行。
5. 原文歧义不凭常识补正：联合流量测定句、压力开关与电流测量关系、1860 的 nut/key 同号冲突均保留未决。跨越两条显式因果边的关系不当直接邻接边；引用可定位不等于该邻接关系获得支持。

参考总账始终显示原 85 项。启动灌液、慢开出口阀、排液后恢复运行三项改为操作旁路；联合流量测定与两项 1860 名称绑定暂列未决。其余 79 项用于本轮暂定核心参考覆盖。原 18 项辅助/未决参考也保留并补上响应位置。分母变化属于任务约定变化，不是模型提升。

## 2. 三组及其能力边界

- A 原始输出：233 条不改字；按同一 v3 技术裁定统计。E0/E1 分开报，再合计，避免把提示差异当作后处理效果。
- B 仅约束筛查：可执行固定规则只读原始断言、引用与 Schema，不读技术标签、参考匹配、记录 ID 或 E0/E1 臂名。检查类型、出处、负向要求、动作目标、检查仪器误绑和部分条件/模态警示。只留或隔离，绝不自动改字。
- C 源文修复：在全部原始输入上重放本轮**AI 逐条源文编修账本**，补充可定位上下文、修正关系/对象/条件、转存操作/负向要求，未决隔离。最多一个原候选对应一个修复输出；不从参考生成缺失条目、不把全局更换标题展开成六条新边、不从辅助输出导入新的核心断言。

C 是有明确人工式编修成本的开发诊断/修复可行性组，**不是已经自动化的抽取算法**。相同助手看过数据、参考与臂名；其修复后支持裁定不是独立效果验证。“修复后未再标出错误”不构成零错误证明。不把按 ID 编修的账本投入运行时门控，不据此声称硕士算法贡献已成立。

## 3. 断言与修复账本

每条记录保存原始内容和哈希、原页哈希、源文片段的真实偏移或原生单元与已有 bbox、原裁定、问题类别、修复字段、修复理由、修复后状态。多证据片段各自独立定位，不拼接伪造连续原文。中文修复说明与源语言表面分开；不写回中文主图。

裁定分 `complete`、`incomplete`、`representation_error`、`semantic_error`、`unresolved`，并另列 core/noncore/auxiliary/background 通道。正确知识误拒严格指原本条件完整且关系支持的 core 记录被 B 拦截；另报有源文知识内核但尚需修复的被拦记录，二者不得混称。类型错误、条件遗漏与事实反向分别统计，不统称幻觉。

## 5. 理论形式与下一道门

诊断单元为 `a=(h,r,t,Γ,m,p,s,e)`。可行修复集合要求出处真实、类型及语义角色合法、条件不弱化、极性不翻转、scope 不无证扩大；目标是在该集合内以较小编辑代价保留较多受支持知识。若源文存在多个相容但不同解释，输出未决而非选最有利版本。本轮账本检验这些约束能否解释损失、能否恢复已有知识；尚未学习或实现通用的语义蕴含器与最小编辑求解器，因此不能将这项形式化本身声称为新理论证明。

冻结本轮审计并不等于冻结可部署方法。开放保留页的必要条件：①通用自动修复实现不读取候选 ID/本轮裁定/参考；②开发页质量与数量联合规则预注册并稳定复现，错误不得以删除正确知识掩盖；③独立评审裁定关键争议并确认源文参考；④固定方法、版本、评价规则，再由源文先行建立保留页参考。未满足时保留页不开，API 不扩量。专家评审属于离线评价，不成为运行时逐条审批。
