# RP1：29个保留页三组对照结果

2026-10-04。**本轮已经完成，现有修复方法未通过扩大抽取条件。** 修复组相对机械筛查多保留3条，但完整支持核心知识仍为16条、完整参考匹配仍为14项，问题放行从22条增加到25条。现在不宜直接扩大API抽取规模。

本轮采用此前冻结的源文支持评价口径，由AI逐项核对。S表示对象、方向、条件、范围和模态完整的支持记录；E包括表示错误、条件缺失、范围问题及错误引用，不等于每条均为虚构事实；U为未决。指标是同文档保留页上的源文支持与固定参考覆盖，不是专家确认的准确率或真实场景召回率。

**实际完成的工作**

- 原定15份构建文档的29页全部完成，每页一次E1，返回模型均为`qwen3.8-max`。29份原始响应、解析结果、请求身份、用量和时延均已保存。这次续接复用了完整响应缓存，没有重复发起请求。
- 获得322条原始assertions，另有60项模型辅助内容，辅助内容不混入三组主比较。相同322条输入形成966项处理决定。
- 对原始输出、仅机械筛查、冻结的v4.1 roles + clause_binding_v1 repair进行对照。六页开发集233条既有结果精确重放一致；没有重训、更换模型或按保留页结果修改处理规则。
- 328个不同“页面＋完整输出载荷”分别留存裁定；相同载荷跨组复用同一判断。六个载荷差异来自修复，其余保持不变。
- 抽取前冻结的118项参考不变，覆盖11页。其他18页因背景、结构图、目录、范围不符等原因没有核心参考，仍保留在29页评价中，不替换为信息更多的页面。

**损失来自哪里**

1. **关系方向错误是实质问题。** 原始322条中78条首要问题为关系方向，包括MP007 p29的43个部件清单条目被写成“部件contains整泵”。部件名称可能真实，但图关系不可直接使用。另21条为类型/关系域错误。
2. **源文读取与定位也在丢失正确知识。** 机械筛查损失19条S，其中8条是核心；这8条全部仅因`unbound_quote`拒绝，来自MP019 p48的2条和MP021 p15的6条。全部19条中18条仅有此标志，1条还触发条件显式化检查。连续字符串定位失败不能直接当成事实错误。
3. **多栏文本既会造成误拒，也会造出错误关系。** MP021 p15把左栏“suction piping”附近文字与右栏“errors in piping layout or assembly”串接成一个新原因。该错误串接反而能在冻结解析文本中定位，三组均未拦住。只检查字符串连续出现不足以保证语义支持。
4. **维护条件被拆散。** 原始结果中16条首要问题是程序前提不完整，14条是润滑材料/周期/相容条件不完整。只补一个if从句难以恢复这些要求。材料名称被当作MaintenanceAction、把运行准备算维护，也会虚增核心量。
5. **表格或结构数量不能替代任务覆盖。** MP004 p30有43条结构记录，即使局部部件归属有支持，也不增加故障/检查/维护参考覆盖。不能用总条数说明已解决知识图谱的实用规模问题。

上述分类是每条记录的首要问题，完整理由以逐条裁定为准；不把同一记录的多个错误反复相加。

**覆盖分母及未决项的解释**

118项参考是在看新抽取结果前制作并冻结的。部分参考本身将动作、材料和条件组成较完整的单元；有支持的较细粒度原子不一定能完整匹配。例如入口压力不足→汽蚀的直接边可判S，但不足以覆盖同时包含高温/高转速入口压力说明的冻结参考。这些部分匹配单列，不计入14项，也不因为未匹配就自动判E。

一条复合候选即便涉及多个参考，也最多占一个匹配。例如高振动对轴承、轴封、电机轴承寿命的复合陈述不能算三次。缺参考的真实候选仍可计入S。未决的因果附着、结构粒度和条件组合留存为U；没有为了填满分母强判。

因此，11.86%应读作**当前完整表示契约下的固定参考覆盖**，不能读作“页面知识只有11.86%被模型看见”。但其绝对量和相对对照都不支持扩大本方法。

**预设判定与下一步**

扩大条件判定为FAIL：相对原始组错误放行减少；相对机械筛查完整支持量、覆盖和正确知识损失持平；但问题＋未决增加3条，且没有任何一页获得严格有效增益。29页不用于继续调参再宣布通过，旧strict208及RP2/RP3教师保持原样。

下一轮应收敛为一个小改进：先在原六页开发材料中解决**多段证据绑定、关系方向、局部条件附着**，再用另一小组未见页面验证；暂不做大规模重新抽取，不继续堆叠模型或广泛规则。明确的关系反转可以有条件修复，无法唯一确定的关系保留原输出和未决原因。新方法形成可审查的差异后再冻结，不承诺本轮没有验证的收益。

从理论上，固定参考下单纯筛查得到原始集合的子集，其最大一对一覆盖不可能超过原始集合；提升比例与增加有效知识是不同目标。这个单调性是评价依据，不是原创算法贡献。论文可继续围绕“保留来源与限定条件的受约束修复”建立方法，但其贡献需要由新增正确知识、误放/误拒和页面覆盖共同验证；本轮不能把开发集有效的规则推广写成已获成功。
