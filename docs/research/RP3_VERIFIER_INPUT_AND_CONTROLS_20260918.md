# RP3 核验器输入与后续对照决策

日期：2026-09-18。依据：[`构建集任务—监督对齐审计`](../RP3_TASK_ALIGNMENT_V1_RESULTS_20260918.md)。
状态：任务和输入边界已明确；对照为待制定执行协议的候选，**没有开始训练，也未正式替换RP3主方法**。

## 1. 目标选择

先研究冻结RP2两阶段核验程序的可替代性，目标是教师相对的一致性与成本，
不宣称训练出了专家级、上下文无关的“证据是否真实支持”判别器。

对查询\(q\)和可用候选集\(A\)，保持：

\[
C_K=T_{\mathrm{select}}(q,A),\qquad
y=T_{\mathrm{verify}}(q,C_K),\qquad
S_T=G(q,C_K,y).
\]

\(T_{\mathrm{select}}\)为冻结RP2选择程序，\(G\)为冻结确定性guard；候选方法仅近似中间核验。
\(K\le3\)来自实际选择结果，不能将“Top-N逐条判别后补满3条”称为相同教师。
冻结选择器仍需查询编码、候选评分和来源约束成本，保留这些步骤后的收益只能据全链路测量主张。

这个分解改变了当前四头整体蒸馏的研究对象，属于显式范围候选；现有负结果不改名、不撤回。
它是任务定义，不是创新性定理，也不证明小模型会成功。

## 2. 输入和标签

| 项目 | 候选输入/监督 | 禁止替代 |
|---|---|---|
| 查询 | 原始查询文本、已给定故障名称/范围、单一请求角色 | 猜测故障类别、将多角色完整诊断卡混入现有任务 |
| 证据 | 实际送入教师的有序K3；各项规范化Claim、关系、原文、角色和目标位置 | 只用ID记忆答案；将未进入K3的尾部标签冒充本次K3监督 |
| 可用性 | 由原选择程序从可用池构建当前K3，padding位置显式屏蔽 | 删除证据后继续使用旧K3；把不可用项作为负支持例 |
| 支持目标 | 对应实际K3运行的合法最终mask | 以是否最终入选反推支持；把`not_assessed`改成0 |
| 最终输出 | 预测mask经原guard生成选集；输出ID必须来自当前K3 | 从尾部补满数量；跳过Claim去重或作用范围规则 |
| 标签来源 | 保留run、stage、提示词、父场景及响应哈希作为审计元数据 | 将标签、final mask、最终选集或事后review路径作为学生输入 |

已有13组冲突中，点式\((q,e_i)\)不足以精确表示全部记录；有些同一证据位置也不变。
有序K3是与实际教师输入对应的候选观测边界，优先于继续加入全池均值。
但“本批加入实际提示上下文后没有标签别名冲突”不等于统计可学习性或泛化保证。

审计另发现6条派生卡片的展示顺序沿用原候选位置，虽然集合相同且`teacher_score`顺序正确。
新数据适配必须读取实际核验运行的有序证据列表并与保存提示词核对，不能直接读取旧`decision.rank`。
在新适配器中明确区分输入位置、选择分数和输出展示顺序；不修改历史冻结bundle。

若未来研究两阶段分解，第一阶段学K3 mask，第二阶段学单证据复核时，必须保留其**条件采样**：
第一阶段为1时第二阶段未执行，不能伪造其0/1标签。对未执行路径的反事实性能目前不可识别。
因此本轮先定义最终mask模仿；阶段分解只作为后续独立假设，不同时叠加。

## 3. 最小对照框架

以下是审计后决定的对照关系，不是已经预注册的数值配置，也不授权自动执行新教师生成。
独立数据协议与具体模型设置冻结之后才能开始。

| 对照 | 作用 | 要求 |
|---|---|---|
| T0：完整冻结RP2教师 | 选集和成本参照 | 当前质量直接引用原记录；新端到端测量单独授权/记录，不能把缓存时间当7B计算时间 |
| V0：点式轻量核验 | 测试简化输入的局限 | 只看查询与目标证据；与V1使用同一批实际K3标签，保留冲突 |
| V1：有序K3条件核验 | 检验目标所需上下文是否带来增益 | 与V0参数预算/初始化/训练设置配对，仅改变可见上下文；不重跑旧S0/S1 |
| 简单确定性接受/回退策略 | 检验是否需要更复杂控制 | 在冻结的同一局部提案上比较固定阈值、始终本地、始终教师、始终拒答 |

尾部单证据标签如果以后用于辅助训练，必须单设有/无辅助监督对照，按不同源运行去重和计权，
不与上述输入对照同时改变。三固定种子仍采用7042027/7042028/7042029，但种子不能替代新独立场景。
旧C0、A2等只作历史参照；由于候选形成和预测目标改变，不能把历史分数直接当新任务的匹配控制。

主要判断应落到单查询最终证据集合：非空精确一致、Pointer P/R/F1、教师非空被预测为空、
教师空集误填、回答覆盖、条件教师不一致、完整教师调用数，以及包含检索/编码/核验/guard/网络的成本。
候选AUC或回答数量只能作为补充。所有指标按基础场景聚合，原始与派生分开。

## 4. 数据与评价门槛

当前只有8个训练和2个验证故障类别场景、四种共享表面模板，没有独立运行工况。
符合真实K3核验任务的mask位仅261/71；数量增加不足以证明独立覆盖扩大。

恢复训练前应先形成可审阅的新数据/评价协议：

1. 只在15篇构建文档内盘点可形成的查询族，明确可见故障范围、角色、条件、否定和来源。
   新问题需有原文依据；同问题改写、同事件证据删除、同源重复不能冒充独立查询族。
2. 先定义基础场景/查询族ID和分组规则，再生成监督、固定划分；同族所有角色/改写/干预留在同组。
   旧8条验证问题保留为历史审计，不能因继续复用而称新独立验证。
3. 继续声明固定记忆边界。若要求未见文档泛化，须另设协议并从检索前隔离文档/来源；
   不能在当前共享208记忆上换个统计分组就声称已做到。
4. 模型选择、阈值/风险校准、最终评价需要明确独立职责和样本来源。
   MP008现有门槛不可行须另行评审，保持旧报告/门槛；MP009–MP013继续外部专用。

本轮决策是先完成上述协议和覆盖可行性盘点，不立即进行V0/V1训练或增加新的encoder搜索。

## 5. 理论和实际效用的成立条件

待检验目标可表述为：在规定的非空服务覆盖和教师相对集合风险要求下，最小化期望完整执行成本。
对接受事件\(a=\mathrm{local}\)，需要明确风险是
\(\Pr(\hat S\ne S_T\mid a=\mathrm{local})\)，而非全样本被拒答稀释后的错误比例；
零接受时条件风险未定义，不能记为0。空预测也不等于已确认无证据，通常仍需回退。

同一guard下mask完全一致蕴含最终选集一致，反向不成立（guard可能去重或过滤）。
因此监督mask、检验最终集合是相容的；仅给出这一蕴含、普通并集上界、阈值或KD损失
仍不构成原创算法贡献。新贡献还需针对实际约束提出区别于现有级联/拒绝学习的方法，
给出可检验假设或保证，并超过匹配的简单控制。

停止条件：如果新数据仍无法提供独立覆盖，或V1不能在保留非空服务与误填约束下增加正确本地提案，
不继续堆叠路由公式、损失或编码器。应继续收窄研究主张，不能将结构性重命名当作优化成功。
