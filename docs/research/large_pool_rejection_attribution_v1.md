# 326页大候选池拒绝与待审系统归因

审计日期：2026-07-26  
审计对象：779条候选（原始严格结果：128条Silver、148条待审、503条拒绝）

## 1. 503条拒绝记录

拒绝原因可以重叠，因此各原因数量不能相加为503：

- 413条包含证据无效；
- 253条包含关系Domain/Range不合规；
- 164条包含关系不由原文直接支持。

证据无效的主要结构原因：

- 306条E2表格证据未经视觉版面确认；
- 132条缺少列名；
- 60条跨表格行；
- 24条头实体不在指定表格单元；
- 50条尾实体不在指定表格单元；
- 61条E1原文跨度无效；
- 46条未形成有效证据等级；
- 9条证据含省略号。

上述原因可能同时出现在同一记录。第二语义模型不能修复缺失的原文、错误表格行或无效页面定位，这类记录必须继续拒绝或回到页面解析和Stage 2重抽。

## 2. 253条关系类型不合规记录

不存在未知关系名或未知实体类型；253条全部是已知关系与已知类型之间的Domain/Range不相容：

| 失败方式 | 数量 |
|---|---:|
| 仅尾类型不允许 | 122 |
| 仅头类型不允许 | 69 |
| 头尾类型都不允许 | 62 |

出现最多的模型关系为：

| 关系 | 数量 |
|---|---:|
| `mitigated_by` | 55 |
| `inspected_by` | 54 |
| `contains` | 49 |
| `indicates` | 47 |
| `causes` | 19 |
| `increases_risk_of` | 12 |

因此不能用字符串别名或放宽Schema整体解决。已实施两类保守修复：

1. 类型唯一的通用规范化，例如：
   - `MaintenanceAction mitigated_by FaultMode`反向为`FaultMode mitigated_by MaintenanceAction`；
   - `Symptom inspected_by InspectionAction`规范为`Symptom diagnosed_by InspectionAction`；
   - `FaultMode indicates Symptom`规范为`FaultMode manifests_as Symptom`；
   - `Equipment contains FaultMode`反向为`FaultMode occurs_at Equipment`。
2. 8条经过逐记录证据审计的白名单修复。每条规则绑定原始`triple_id`和预期类型，字段不一致时失败关闭，不向其他记录泛化。

规范化后：

| 决策变化 | 数量 |
|---|---:|
| 拒绝 → Silver | 15 |
| 拒绝 → 待自动语义裁决 | 31 |
| 仍拒绝 | 457 |
| 原128条Silver保持Silver | 128 |
| 原148条待审保持待审 | 148 |

新的本地严格结果为：

- Silver：143；
- 待自动语义裁决：179；
- 拒绝：457；
- 关系类型不合规：由253降至112。

剩余112条不允许继续机械改写，主要包括：

- 保护装置或阀件“防止”故障，但当前Schema没有`prevented_by/protected_by`；
- 工况“增加某故障风险”，但`increases_risk_of`当前只允许尾实体为`Risk`；
- 报警阈值、症状发生部位和类型层级缺少专门关系；
- 维护动作自身引入故障，但当前`causes`不允许`MaintenanceAction`作为头实体；
- 否定遗漏、实体边界错误或不同列表项拼接。

这些记录应保持拒绝，并在后续Schema版本中单独论证是否增加关系，不能为了提高覆盖率扩宽现有Domain/Range。

## 3. 179条待自动裁决记录

其中157条满足自动语义裁决的结构门槛：

- E1或E2；
- 证据有效并具备自动Silver资格；
- 关系类型和方向合法；
- 当前仅关系语义蕴含未确定；
- 构建集、非推断边。

其余22条为E3重建证据，永不自动进入Silver。项目不要求非轮机专业用户人工审核，而采用双重拒绝优先语义裁决：

- 两次裁决均为`entailed`；
- 两次置信度均不低于0.90；
- 两次支持引文均能回落到原文；
- 任一次`not_entailed`或`uncertain`都不晋级。

该过程仍是AI辅助Silver治理，不是人工Gold标注，也不构成专家审核。

## 4. 关系规范化后的覆盖

目前仍只有“流道、叶轮、过滤器或管路堵塞”通过覆盖门槛。规范化主要增加了轴承/润滑、不对中、叶轮维护等证据，但症状、检查维护和独立来源缺口仍然存在，因此已经按`document_split_marine_pump_v3`新增MP017–MP021五份独立来源。
