# RP1 独立模型交叉复核结果与待交付的人工评价

日期：2026-10-03。**22条本地第二模型意见已全部完成；独立人工复核尚未完成，正式方法冻结和29页保留评价未启动。**

## 已实际完成

- 将六页开发材料整理为一份可填写的独立复核包：6页源文优先清单、5个口径问题、22条候选、85项原暂定参考比对。
- 22条候选包含10条本轮方法命中记录，以及每页另外按固定哈希抽2条、共12条对照。没有依据模型结果改变样本。
- 使用本地Qwen2.5-7B-Instruct执行一次隐藏原结论的S/N/U复核。模型只接收断言、完整页面文本、原生表格行和适用元数据，不接收原AI标签、候选组别或放行状态；未进行PDF视觉复核。
- 运行使用CPU FP32、10线程，模型权重与旧本地第二意见记录逐文件SHA256一致。最长输入1705 token，22条全部实际核验，无截断、无超限跳过；总运行1659.9秒，约27.7分钟。
- 推理完成后才将模型意见与旧AI技术标签关联。没有重跑原26条第二意见、旧抽取、教师或学生实验，没有调用外部API。

## 结果

| 原AI技术裁定 | 第二模型S支持 | 第二模型N不支持 | 第二模型U未决 |
|---|---:|---:|---:|
| S：完整支持 | 13 | 0 | 0 |
| N：表示/条件等问题 | 8 | 0 | 0 |
| U：未决 | 1 | 0 | 0 |
| 合计 | **22** | **0** | **0** |

与原AI裁定一致13条、分歧9条。10条定向变化样本中有4条分歧，12条抽样对照中有5条分歧。13/22是两个自动评阅者的意见一致数，不是准确率；任何一方都不是专家真值。

模型对所有输入都选择S，普通未限制词表的下一token也都在S/N/U内，因此不是把非法文本强行映射为S的解析错误。但它没有区分原AI标注的问题和未决记录，**不能用其全支持结果证明修复质量、裁定争议或替代独立人工标签**。这也不能反过来证明原AI裁定全部正确。

受限单token评价没有逐项自然语言论证；条件概率未校准。抽样含定向记录，两模型还同属Qwen家族；不能把独立调用解释为统计独立的错误来源。本轮不调整提示、分数阈值或方法来追求意见一致。

## 实际需要补什么

需要一位具备相关专业背景、未生成现有AI标签的第二位评审完成[独立复核包](../../results/experiments/research_point_1/independent_review_v1/README.md)，或提供已经完成的独立复核文件。专业背景据实记录；没有领域专家资格时称独立技术复核。它仅用于论文实验评价，运行时不增加逐条人工审批。

真实复核交付后，检查并封存参考/争议处理和方法，再打开29页进行源文优先参考构建及固定对照。保留页最小设计已经写好：每页一次E1抽取，同一输出比较原始、机械筛查、最终修复三组；不扩展为更多模型或优化版本。详见[复核与保留页流程](RP1_INDEPENDENT_REVIEW_AND_HOLDOUT_V1_20261003.md)。

如果暂时没有真实评审条件，这里应如实保留待完成状态；本地第二模型的这轮全支持结果不能作为已经满足人工评价条件的凭据。
