# RP1：布局、关系方向与条件绑定的新页面验证结果

2026-10-04。本轮已完成开发、方法冻结和8个新页面验证。**布局处理救回了10条原本被拒的、有完整源文支持的核心知识，但同时多放行13条核心问题记录；完整修复组未通过预定比较条件。** 目前适合保留布局模块的证据与实现，继续解决关系表示问题，尚不支持直接扩大抽取规模。

本轮使用AI逐项源文核对。S表示当前命题的对象、方向、范围、条件及模态有支持；E包括关系/类型错误、条件缺失、模态加强和引文改写，不等于每条都是虚构事实；U表示源文附着或表示方式未决。数值是本批次的源文支持与固定参考覆盖估计。

**完成了什么**

1. 在原六页233条真实缓存上比较B/L/D/C，没有重复调用API。B为冻结的旧`clause_binding_v1`修复；L增加原生文本行/单元证据路径；D再增加保守方向修复；C再增加局部条件、模态及替代动作检查。
2. 开发后冻结代码、测试、协议和旧E1模板，再按固定元数据与哈希顺序选8页。排除130个以前的审查页面；未使用MP008或外部评价文档。
3. 阅读新页面源文，先保存45项核心参考及辅助内容范围说明，再冻结请求。八页分别为MP015 p105/p106、MP016 p12/p21、MP018 p15/p17、MP021 p4/p11；按物理PDF页编号。
4. 8次`qwen3.8-max`请求全部完成，获得141条assertions。原始响应、用量、时延和解析结果均已保存，未进行自动重试。所有组复用这141条输出；raw只作为描述性损失审计，正式改进比较为C对B。
5. 审查146个不同的“页面＋完整载荷”，其中5个是相对原始输出改变过的载荷；相同载荷跨组使用同一裁定。生成705项处理/审计决定、逐项理由、完整/部分参考匹配与误拒清单。

E0为旧直接抽取提示，E1为旧约束抽取提示。两臂各自保持原响应及设置。下表的77项核心参考沿用现有更新口径，旧79项分母的报告保留，不能直接混算。

**三项改进分别起了什么作用**

- **布局恢复确实有效。** 检测到MP016 p12/p21及MP021 p11为双栏。B→L新放行40条，其中19条S、18条E、3条U，同时新拒绝1条非核心S；净增加18条S。10条新增核心S全部来自这里。法文“检查前隔离并锁定电机”、退回泵的清洁去污，以及德文框架变形影响对中等得到恢复。
- **布局不会判定语义。** 法文`pourrait`被写成`probable`、一般危险提醒被写成同义反复的核心风险边等问题，恢复地址后仍存在。恢复引文也会将这类记录重新放行。
- **方向模块在新页没有增益。** L与D的全部141条载荷和接纳决定一致。现规则只在原方向不合模式、反向合模式、两个端点均在局部引文且有有限英文角色线索时翻转。大量反向`causes`不在此覆盖范围；“过热→润滑脂搅动”的两端类型本身还都合法。域/值域检查不能代替方向语义。
- **C只新增一项模态修复。** MP018 p17第10条从asserted改为possible，仍有“Failure to observe this”回指替代限制的歧义，单列U。新页没有`LOCAL_ANTECEDENT`触发带来的新增收益，不能宣称已解决程序条件绑定。
- **仍有两个非核心S被拒。** MP016 p12的Clutch资料编号引用跨两个原生单元，新布局判定反而比B严格；MP021 p11的齿轮结构引文仍无法完整定位。原始47条S保留45条。核心15条S全部保留，并不等于所有正确知识都保留。

**为什么完整参考覆盖仍低**

存在真实的方向/类型错误和动作漏抽。例如MP018 p15只输出13条候选，多个润滑程序步骤没有形成可用表示；MP018 p17把检查动作与轴承的`inspected_by`方向写反、把材料当维护动作。这些不能靠引文恢复变成正确知识。

也存在参考粒度的影响。参考在抽取前已冻结，部分包含组合动作或附加限制。例如“压力设定后紧锁母并装回盖垫片和阀盖”为一个组合参考，模型拆出的三个真实部件动作各可判S，但任何一条都不足独占该组合参考；这里没有合并它们或扩大匹配数。C中有5个未完整匹配的参考，被至少一条S部分覆盖，分布在MP016 p21、MP018 p15、MP021 p11；这5项不计入6项完整匹配。

因此13.33%是**当前冻结完整命题口径的覆盖率**。它不能直接解释为“模型只看见了页面13.33%的知识”。部分匹配清单还包含E/U记录碰到的知识主题，后者也不能当作正确召回。后续若调整参考粒度，应另起评价版本并先固定规则，不能改写本轮分母。

**理论内容与目前可支持的论文表述**

将待发布知识写为`z=(h,r,t,κ,μ,s,W)`：三元组、条件κ、模态μ、适用范围s及来源地址集合W。布局模块在真实行框/单元上构造可接受阅读路径，得到证据候选；关系类型和局部语义限制可接受的修复集合。证据无法唯一定位或修复仍有歧义时保留隔离。

实现可检验的不变量有：输入页与原始响应不变；引文地址可在原字符上回读；每个原始候选至多产生一个结果；方向修复保留条件和范围；新增条件只能来自局部同一句命题；既有拒绝理由除定位问题外不被随意清除。这里的唯一性是**给定阅读路径和有限规则集合内的唯一性**，不能提升为全部语言解释的唯一性。

此次实验支持“布局感知证据路径能够减少机械定位造成的正确知识损失”这一具体贡献。它尚未支持“方向和条件自动修复提高整体知识质量”。最小改变、类型约束与来源追踪属于已有方法原则，不能单独包装成新的普适理论。硕士课题可以围绕条件化证据表示、可回读的有限修复及质量—保留量权衡展开，但实用效果必须继续由完整对照支撑。

**适用边界与执行记录**

- 八页来自同四份构建文档，包含相邻页面，并非八个独立现场案例或文档隔离外测。旧29页结果不重算，本轮不声称相对旧29页的绝对准确率改善。
- MP016元数据标`en`，实际p12含英语/法语，p21为德语。发现后没有替换页面。几何定位可跨语言工作，冻结语义规则只覆盖有限英文，因此语言差异会影响本批表现。
- 本轮AI参考和裁定由同一助手完成，有判断偏差风险；未伪称盲态独立专家评估。逐条理由和原文地址公开在仓库产物中，方便后续重算。
- 8次调用共97,475输入token、18,322输出token，总115,797；请求响应耗时合计318.24秒。这是客户端请求耗时，不是完整实验墙钟时间或边缘推理时延。后处理和评价增加API调用0次。
- 原拟调用曾被自动审批拦截；随后从四个厂商公开URL下载文件并验证与本地PDF逐字节哈希一致，补充公开数据证据后审批通过。凭据仅从隐藏输入进入进程内存，未存入实验文件。
- 43项相关测试通过；196个旧冻结依赖核验未变；705项决定和146个载荷核验完成；1,388次来源地址回读检查通过（含跨组重复）。使用另一种子集动态规划算法复算40组页面指标/匹配，并反序重放564次B/L/D/C纯函数结果，全部一致。

**下一步控制工作量**

本轮保留页已经揭示方向规则覆盖不足和程序条件缺失，不再拿这8页修改规则后重报成绩。下一次仍回到旧六页，优先做一个简单对照：直接输出关系，与先输出“原因/结果、检查对象/检查动作、维护对象/动作、触发条件”角色槽后由固定模板生成有向边。先用233条缓存检查错误覆盖和反例，再决定少量新调用。布局模块可继续作为证据定位基础，扩大15份文档抽取尚无充分支持。
