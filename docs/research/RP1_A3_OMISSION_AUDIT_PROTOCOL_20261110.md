# A3研究动机验证：原文关系是否在原始候选中完全遗漏

日期：2026-11-10。A3在本轮特指证据驱动候选恢复。只作诊断，不实现恢复算法，不改图谱或RP2/RP3教师。

## 样本与评价口径

从已保存完整源文和模型返回的39个既有开发目标页中选24页。
只根据源文中的故障、因果与检修词密度排序，单文档最多3页，以固定哈希打破同分。
不按候选数、旧参考覆盖或遗漏多少选择页面。全量排序及选中清单在prepare时封存。
词密度只是定向选页信号，不证明该页所有内容属于泵系目标关系。低信息或范围不符页仍保留。
构建集之外的MP008、MP009–MP014不进入本轮。

39页均已参加过开发或被分析过，评阅人知道部分旧结果。本轮不是新外测、随机总体抽样或完全盲法。
先读本轮选页源文，每页最多固定4项清楚、原子的诊断/检查/维护命题，再打开完整原始输出比较。
重复知识、同一句的机械拆分、间接因果推导不增加参考数量；没有合适目标的页记录理由，不换页。
参考为本次助手源文AI审计，不是人工或专家真值，不声称已穷尽页面知识。

## 重点区分

| 类别 | 判定 | A3意义 |
| --- | --- | --- |
| 完全候选遗漏 | 明确命题在实际输入中可见，但全部原始主候选、辅助和未决项均无对应关系 | 核心目标 |
| 关系/角色错误 | 已有对应实体关系，但方向、类型或作用对象错误 | 辅助目标，不计完全遗漏 |
| 验证拒绝 | 原始已有完整正确关系，冻结校验分支将其拒绝 | 不是A3核心 |
| 已有候选 | 原始关系已表达，无论最终是否进入图谱 | 不支持完全遗漏动机 |
| 表达不完整 | 原始已表达核心关系，但缺条件/范围等 | 不计完全遗漏 |
| 辅助/通道排除 | 关系已生成在辅助项或被标为背景等通道 | 不计完全遗漏 |
| 输入/接口缺口 | 原文未送入实际提示，或受限菜单无法表达端点 | 与LLM未识别分开 |
| 未决 | 源文、角色或候选等价性无法确定 | 保留，不强判遗漏 |

含辅助、未决项的全部解析输出都要搜索，不能只查主图谱、放行记录或旧参考的一对一匹配。
29页批次为自由输出，10页批次使用端点菜单；严格LLM遗漏结论先限定在自由输出批次，菜单批次另记接口局限。
原始二进制响应不在当前Git输入中；核对的是保存的有效解析JSON、完整结束元数据及逐条血缘。
结论准确表述为“已保存且核对完整性的原始JSON候选中无对应关系”，不扩大为模型内部从未形成过相关知识。

## 检查与成立条件

逐项保存原文引句、实际输入可见性、知识方向和范围、对应/最近候选编号、全部字段已读声明及理由。
引文回读、输入定位、候选ID与程序去向由脚本核对，语义等价与类别仍由助手判读，脚本不能证明判断正确。
源文存在多个解释、只有术语共现，或候选已用同义句表达时，不判完全遗漏。

这一轮只回答“是否有跨页面、跨来源的实质遗漏证据”。
遗漏数量与页面/文档分布作为动机材料，不当作全语料候选召回率。
如果遗漏主要是条件不全、角色错误或过滤损失，应收窄或改变A3目标；不能为恢复算法预设结论。
即使证实存在遗漏，恢复方法是否等资源有效仍需下一轮单独对照，本轮不宣称已恢复知识或已取得算法增益。
