# RP3 联合证据契约蒸馏 v1：执行前固定协议

日期：2026-09-17。先完成只读`joint_gating_audit_v1`，再固定本协议；此时尚未训练新臂。
本轮研究对象是请求角色上的支持、字段状态、数量联合约束。排序目标和早停规则保持不变。

## 动机与可证伪假设

训练集129条中32条没有候选，只有5条是“有候选、教师空选集且候选全部已核验为非直接支持”；
验证集对应36/8/4条。没有发现教师选择数量超过已标注直接支持数。
既有7042027的三条误填中，支持、字段、数量都允许输出；分别用对应教师标签替换任一头即可消除误填。
这是联合错误，不是发现解码器违反ID/可用性约束；oracle替换只能定位，不能计入可部署成绩。

H1：提高这类困难空集的监督权重，可减少误填且保留非空请求质量。
H2：在H1相同监督基础上加入跨头契约正则，可进一步改善质量/风险权衡。
H2若失败，不得将H1的收益归因于结构化算法。三个头一致地预测错误仍可能满足契约；仅靠一致性不足以保证正确。

## 算法与理论边界

请求角色为r，可用且角色匹配的候选集合为A。支持头给出p_i，数量头给出q_k（0≤k≤K），字段头给出f_s。
构造辅助因子化分布`P(B,N,F)=∏ Bernoulli(B_i;p_i) × Cat(N;q) × Cat(F;f)`。
这是用于正则化的建模假设，不声称候选在物理上独立。设S=∑B_i，冻结契约的必要条件为：

```text
N ≤ S;
F∈{insufficient,not_applicable} ⇔ N=0;
F=supported ⇒ N≥1;
F=conflict ⇒ N≥2.
```

不强制N=S：直接支持候选可能受预算、来源约束等限制而不被选中。
这也不强制非请求字段产出；只作用于请求字段。冲突语义本身仍由教师/解码契约负责，正则只约束最低数量。

定义`a_0=f_insufficient+f_not_applicable`，`a_1=f_supported`，`a_k=f_supported+f_conflict (k≥2)`。
契约概率质量和损失：

```text
Z = Σ[k=0..K] q_k a_k Pr(S≥k)
L_contract = -log Z.
```

用截断Poisson-binomial动态规划求`Pr(S≥k)`，最后一桶为`S≥K`，而不是丢弃K以上质量。
每纳入候选i：中间桶`d'_j=(1-p_i)d_j+p_i d_{j-1}`；末桶`d'_K=d_K+p_i d_{K-1}`。
时间O(|A|K)，推理不新增头或网络。训练中对Z做[1e-12,1]数值截断。

可验证性质（本项目推导，非新的一般性定理）：

1. 递推等价于对独立Bernoulli全部赋值求和，桶概率非负且总和为1；由条件分解得上式Z。
2. 辅助分布的违约概率为`1-Z≤-log Z`（log不等式）；这是模型分布内部的约束量，不是现实误诊风险或确定性argmax违约率保证。
3. 将辅助分布条件化到契约集合C，`Q=P(.|C)`有`KL(Q||P)=-log Z`；更一般地，任何支持在C内的R满足
   `KL(R||P)=KL(R||Q)-log Z`，故Q是该方向KL的最小投影。实现只惩罚此投影距离，没有用投影后分布替换解码器。
4. 无候选时S=0，正则仅允许零数量且空字段状态；不可用/错角色候选不影响Z，对其支持logit的该项梯度为0。

这个构造属于已有语义损失/约束后验思想在RP3证据契约中的应用，不能把通用框架宣称为原创：
[Xu等，ICML 2018，Semantic Loss](https://proceedings.mlr.press/v80/xu18h.html)；
[Ganchev等，JMLR 2010，Posterior Regularization](https://www.jmlr.org/papers/v11/ganchev10a.html)。
硕士课题可检验的贡献是证据契约的具体因子化、可用性条件化的可计算约束，以及困难空集与非空覆盖的受控权衡；目前只是候选方法。

困难空集集合H要求：教师请求数量0、至少1个可用同角色候选，且这些候选全部已核验标签为0。
`not_assessed`不能充作负标签，含未核验候选的行不进入H。额外监督：

```text
L_H = (1/|H_train|) Σ[x∈H_train] Σ[i∈A_x] softplus(s_i)
```

此处s_i为支持logit。minibatch无偏估计使用`mean(1_H × sum BCE) / π_train`，固定`π_train=5/129`；
validation也沿用训练比例，不根据validation频率重估。没有H样本的batch贡献可微零值。
在H上，原解码器若误填，至少一个候选p_i≥0.5，故`1[误填]≤Σ softplus(s_i)/log 2`。
这是固定0.5解码下、这些已标注困难空集上的点态代理上界；不能推广为有限样本安全证书，也不使用MP008调阈值。

## 判断、正确性与保留

继续分别报告original/derived/all、train/validation，基础场景宏平均再汇总三个种子均值、SD。
主要指标仍为非空目标raw零预测、请求raw/decoded基数准确率、Pointer P/R/F1；另报全部教师空集、
困难空集、无候选三种误填分子/分母，raw三头离散违约率、平均1-Z、非请求字段原始误填。
原始validation仍只有2个故障场景，派生轨迹不增加独立样本数。

比较W1/C0、J1/W1，并补充J1/C0：只有原始validation场景宏三种子平均F1不降低、raw零预测不升高、
raw基数准确率不降低，且每种子完整validation教师空集误填不增加、零可用证据误填0、输出契约无违规，
并在前三个质量指标或平均教师空集误填中至少一项严格改善，才标为该配对的内部Pareto改善。
J1还必须较W1降低完整validation平均模型违约质量`1-Z`，才能同时标为“契约优化且质量/风险有增益”。
该判断不等于统计显著性或部署资格；平均违约下降但质量下降时必须判作权衡/未证实。

实现验证必须包含：小候选穷举与动态规划一致、总质量守恒、掩码梯度隔离、无候选/极端logit/冲突最低数量、
梯度数值检查、未知支持标签排除、困难代理上界及默认零权重兼容。真实轨迹先检查教师数量/状态/支持的可行性。
