# RP3 构建查询族覆盖可行性实验

日期：2026-09-18。本轮是在初步盘点之后固定的**探索性数据设计审计**，不声称盲态预注册。
配置：`configs/research_point_3/query_family_feasibility_v1.json`。

## 问题与边界

检验严格208图能提供多少有出处的故障查询范围，以及这些范围在明确依赖规则下还能分成多少组。
不调用教师、不生成支持标签、不重训学生。旧40问、原train/validation、208图和所有旧模型保持不变。
这一步对应恢复V0/V1前的数据可行性门槛，不能用“增加问题行数”替代独立覆盖。

仅语义读取15篇构建文档的已有解析页、冻结严格图与training记忆。MP008和外部资产仅可为保存性检查读取字节哈希。
原始PDF、响应、checkpoint、ONNX、报告和日志全部保留。输出目录已存在时拒绝执行。

## 可复核操作

1. 核对208条记忆的Claim/实体绑定、角色方向，以及原文页SHA、文档SHA和已有定位。
   E1按连续字符跨度核对；E2按`source_records`已有单元ID、单元文本、表/行和bbox核对解析页表格。
   不把E2虚构成连续跨度，不向冻结compact memory补写bbox。此处原生E1/E2分支是首次执行遇到
   E2空offset后修正的实现假设，初次失败日志与源码保留；不是源数据损坏或新抽取。
   第二次执行暴露已保存单元的列名注释差异和一处纯空白差异。单元定位按ID、表、行、bbox严格相等，
   文本核对非空白字符逐字相等；另逐项输出列名/空白差异，不能声称所有原始表示字节一致。
   文档SHA只核对冻结记录与解析页的绑定，不声称本轮重新计算了PDF哈希。
2. 列出所有`FaultMode`实体作为**候选故障范围**，保留规范中文名、原语言表面及全部入射证据。
   冻结实体类型本身也是自动标签，不是专家确认。不能将所有head（其中包含原因、部件）直接当故障。
3. 按关系方向标注可作为问题撰写依据的证据：`causes`取tail；`indicates`取tail；
   `manifests_as/diagnosed_by/inspected_by/mitigated_by/prevented_by/maintained_by`取head，并与实际role对应。
   **有方向锚点不等于教师支持为1，没有方向锚点也不等于教师支持为0。** 不复制任何新问题的答案或mask。
4. 全部208条参与依赖闭包，包括不生成问题的部件/context条目，防止筛选后断开依赖桥。
   三种规则分别为：共享规范实体/Claim/文档物理页；加已有原语言别名；再加来源族。
   NFKC、casefold和空白折叠仅用于依赖键，原始内容不改写；不把该匹配当作完整语义同义词识别。
5. 每个故障范围产生四个单角色**撰写草案**，不加入未证实工况、运行测量或现场事件。
   列出角色依据、来源适用边界和需审阅原因；所有草案`eligible_for_training=false`。
   四个模板仍只有四种查询意图，不宣称模板多样性或新增现场病例。
6. 仅给出内部pilot分组草案：主规则的最大组放train，剩余组按固定SHA顺序分配；
   前6组validation、接着6组build-confirmation、余组train，至少保留1个训练组。
   所有同组范围/角色一同分配；不均衡如实报告，不根据标签调平。
   这是新版本的**候选划分**，不改旧划分，也不自动授权将旧validation成绩重新当独立结果。
7. 对每种闭包报告组数、最大组、文档/来源族/证据数、范围数、角色依据覆盖、
   范围集中度`1 / sum_g (n_g/N)^2`和草案split的来源交集。
   该集中度只是描述性逆集中度，**不是统计有效样本量**；连通组也不是已证明IID的现场样本。

## 判读与下一阶段

来源族闭包用于压力检查，不能因为组数少就断言点式或上下文学生必然不可学习；
主规则无交叉只证明申明的实体/页依赖被合并，不能证明不存在语义或来源相关性。
数据设计要分别回答：能否进行小规模内部pilot，以及是否足够支持独立泛化/风险认证；两者不可混同。

本轮交付可审阅的逐条来源、查询草案和划分，而不是可直接训练的新benchmark。
启动新监督前须完成查询适用范围/同义范围/因果方向审阅，冻结最终新问题和评价职责。
若范围改成固定记忆内的自动文档查询，需明确它与现场故障任务的区别。
随后才冻结V0/V1相同输入编码器、参数预算、初始化、三个种子7042027/7042028/7042029及停止条件，
以真实新K3运行生成标签；不得用已有标签自动填草案、不得从尾部补位。

只有充分且适当的独立样本才能支撑后续风险论证；本轮不拟合阈值、不生成证书、不修改MP008门槛。
这是实验设计与数据充分性证据，不是原创算法贡献或方法精度改善。
