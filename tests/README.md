# Tests

- `unit/`：解析、Schema、索引、评分、自适应剪枝和提前终止的单元测试。
- `integration/data_pipeline/`：从文档页、候选三元组到冻结图谱和自动证据评价集的数据流水线集成测试。
- `integration/online_retrieval/`：从“结构化查询 + 冻结图谱”开始的在线检索、冷/热缓存时延和资源测试。

`unit/test_research_point_3_*` 覆盖研究点三的数据契约、208教师冻结、top-32轨迹、组级防泄漏切分、证据可用性干预、四头模型与损失、安全解码、代价路由、确定性卡片、工具接口、评价以及训练/ONNX清单。当前阶段只生成测试代码；按本机不运行LLM的要求，不在这里记录任何训练或性能通过结论。
