# Research Points

`src/` 按当前硕士论文的三个研究点组织。旧目录名作为复现实验兼容路径保留，不据此解释研究点含义。

```text
src/
├── research_point_1_graph_evidence/  自动证据契约门控与可追溯知识图谱构建
├── research_point_2/                 预算约束型混合证据选择与核验负载控制
└── research_point_3/                 可调用轻量证据控制器与选择性边缘推理
```

研究点一生产可回溯到原文的自动证据合格记录；研究点二在固定证据预算内选择、核验并确定性呈现这些记录；研究点三将“选什么、是否支持、何时欠填、回退或拒答”的策略蒸馏为供LLM/编排器调用的轻量证据控制器。

通用数据结构只有在出现稳定跨研究点复用需求后才进入 `src/shared/`。研究点三不得复制研究点一、二的实验目录充当训练代码，也不得改写任何已冻结上游资产。
