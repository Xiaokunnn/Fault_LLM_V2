# 研究点一：自动证据质量门控与可追溯知识图谱构建

本目录实现研究点一的小论文方法：大模型从船舶机舱泵系技术文档提出候选三元组，系统在不逐条进行人工审批的条件下，用冻结的可执行规则检查结构、证据、来源和术语发布条件。

## 方法模块

```text
stage01_document_ingest/    坐标保持的PDF正文/表格解析
stage02_triple_extraction/  候选三元组与页面证据提出
stage03_schema_validation/  类型、方向、E1/E2定位、关系和来源契约
stage04_graph_build/        全审计图与分层中文应用图
stage05_silver_benchmark/   历史兼容名：受控证据评价集构造
stage06_retrieval/          研究点二早期兼容实现，正式方法见research_point_2
stage07_evaluation/         契约、来源族、CQ与鲁棒性评价
```

`stage05_silver_benchmark` 和配置中的 `silver` 为冻结路径名，不代表当前研究创新名称。当前叙述使用“候选记录、自动证据合格记录、隔离记录、拒绝记录”。自动证据合格只表示通过所声明的证据契约，不等于专家确认事实。
