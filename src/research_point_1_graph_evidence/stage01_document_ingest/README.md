# Stage 01 - Document ingestion

正式解析器同时保存正文和表格版面：

- 正文生成带阅读顺序和 `bbox` 的文本块；
- 表格保存 `table_id`、`row_id`、`row_group_id`、列名、列角色、单元格原文和 `bbox`；
- PDF物理页码始终确定，印刷页码以带置信度的候选或版本化人工覆盖保存；
- 每次解析前核对PDF字节数、页数和SHA256；
- 输出中固化来源URL、发布者、来源家族、文档划分、泵型、服务场景和适用范围；
- 页级输出增加 `source_language`、语言置信度和检测方法；只做语言识别，不翻译或改写原文；
- 故障表列角色同时支持中英文表头，例如 `Fault/Cause/Remedy` 和“故障/原因/措施”；
- 正式解析拒绝未分配到构建、开发或保留测试划分的本地文档。

解析产物只是证据载体，不直接成为三元组或Silver标签。
