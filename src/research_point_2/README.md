# 研究点二：预算约束型向量—图协同证据检索

本目录实现研究点二的小论文方法。输入查询为 `q=(x,f,r)`：自然语言问题、预先给定的候选故障范围，以及症状、原因/机理、检查、维护中的一种诊断角色。它不是开放式故障识别。

## 冻结v6流程

1. BGE-M3返回top-32候选，top-8证据端点作为图锚点。
2. 一跳图传播提供有界结构信号。
3. 角色与故障范围过滤后，联合稠密分数、图接近度、证据先验和来源新颖性选择最多3条证据；允许主动欠填。
4. Qwen2.5-7B第一阶段输出等长0/1支持掩码，第二阶段只复核首轮为0的候选。
5. 确定性渲染器输出带证据ID的原子建议；无合格证据时拒答。

在线排序不得读取 `fault_class_ids`、`relevant_evidence_ids` 等评价字段。自动查询、相关性和语义支持标签是自动评价资产，不是专家真值。

## 论文结果边界

- 冻结底座：208条严格中文证据、14份文档、10个来源族。
- 40条受控查询：34条可回答、6条不可回答。
- Full K3相对Dense K3将Recall从0.218提高到0.431、NDCG从0.406提高到0.822、Citation F1从0.259提高到0.426，平均端到端时延从839.4 ms降至531.2 ms。
- Full与Full-NoGraph的平均质量差异很小且不显著；图传播仅解释为尾部召回补充。
- 自动双提示审计衡量回答与引用片段的一致性，不是专家确认的维修正确率。
- 实验运行于RTX 5880 Ada 48GB、BF16环境，属于同硬件相对效率，不是船端实测。
