# Research Point 2: Evidence Distillation and Prototype Memory

研究点二为“基于图谱证据蒸馏与原型记忆的边缘轻量化辅助诊断模型”。当前尚未启动，必须等待研究点一低时延图谱教师、目标硬件协议和评价协议冻结后再实施。

方法边界已经在正式研究规划中确定：将教师的证据路径排序、证据类型覆盖、维修动作分布和置信代理蒸馏到轻量学生，使学生不在线访问完整图谱或只使用与模型绑定的极小只读证据字典。主实验采用闭集证据ID协议：测试查询和外部主张可以未见，但目标ID必须已存在于训练标签空间和冻结字典；来源扩展产生的新ID只用于学生分布外识别与回退评价。研究点二不另建一套在线GraphRAG，也不把候选故障分类作为核心任务。

本目录当前只保留边界，不放置研究点一的兼容代码、临时脚本或实验副本。启动时须继续遵守文档级数据隔离、Silver命名和保留测试集不可回流训练的要求。
