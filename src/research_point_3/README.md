# Research Point 3: Calibration and Selective Fallback

研究点三为“面向高风险船舶泵系场景的置信度校准与选择性回退”。当前尚未启动，必须等待研究点二学生输出和置信特征冻结后再实施。

方法边界已经在正式研究规划中确定：低风险查询接受轻量学生输出，中风险查询调用研究点一低时延图谱教师，高风险、证据不足或冲突未解查询转交人工复核。学生接受门与教师接受门分别校准；完整无剪枝搜索只作同一候选空间和评分器下的高召回、高成本离线参照，不作为在线回退服务。

本目录当前只保留边界，不放置研究点一、二的兼容代码、临时脚本或实验副本。启动时须按基础查询和源文档分组构造Silver风险数据，并严格限定校准和风险结论的适用范围。
