## 1. 研究对象与范围

对象为船舶机舱泵及其驱动、密封、轴承、润滑、管路和保护系统。
仅使用 MP001–MP007、MP015–MP022 的构建资料。其他划分不用于规则设计或本轮评价。

- primary：源文明确适用于泵/泵部件或与泵直接连接的驱动、管路、保护系统。
- background：通用可靠性、维修理论或通用旋转机械知识，但本段没有明确的泵应用连接。可保留为背景，不能自动实例化为特定泵故障。

## 2. 关系与限定语义

一个可评价断言为 (主体, 关系, 客体, 条件集合, 模态/极性, 适用对象, 源文证据)。
源文断言的条件集合 Γ 不得在图谱中无记录地删除。形式上，Γ⇒R(h,t) 不能直接改成 R(h,t)。
这是一项表示正确性的约束，不是新的因果发现理论或已经证明的算法创新。

| 问题 | 固定口径 |
|---|---|
| causes / increases_risk_of | 保持方向和可能性；“may”不升级为必然，症状不能无依据倒推唯一原因 |
| indicates / manifests_as | 诊断指示与故障表现不是同一个方向，也不与 causes 自动等价 |
| diagnosed_by / inspected_by | 检测动作或检测方法；铭牌上的额定参数来源不自动成为故障诊断方法 |
| prevented_by | 主体必须是被降低发生风险的事件/状态；“不得用危险方法处理 X”不自动意味着“预防 X” |
| mitigated_by | 已有故障/异常的处理；处理堵塞时避免人身伤害不等同于消除堵塞 |
| maintained_by | 正向维护动作；“无需维护”属于负向维护要求，不发布成正向维护动作 |
| 故障表格 | 症状—原因—措施属于带条件的行断言；症状→措施不能无条件替代原因→措施 |
| 阈值/介质 | 阈值属于被标注的物理对象及介质；冲洗液温度不能转成整个密封的无条件温度上限 |
| 规格/类型限制 | 保留尺寸、压力、材料、型号和工况范围；适用一个子范围不推出全范围 |

未解决的条件附在新旁路记录中，状态为 requires_semantic_review，不伪造结构化条件已被专家验证。

## 3. 证据修复的允许范围

不改变旧原文、ID、定位和决策。新定位建议引用旧记录和源页 SHA256，保存精确原文及偏移/单元。
不合并省略号两端，不倒序翻译成伪原文，不把端点共现当成关系成立。

本轮 B 只实现两个可机械核验的子范围：

1. E1 局部窗口：保留可定位的旧引用，在其前后最多各 400 字符内寻找两个端点；取最小连续区间，最长 1200 字符。仅空白差异可规范化，大小写和非空白字符必须保持。旧 E2 或页面带表格时不通过此路径修复，防止把表格串行化当成正文。
2. E2 同行：端点能在解析器原生单元中唯一绑定于同一表格同一行；单元框有效、在页内并有纵向交叠。保存单元原文字段，不制造 bbox、不推断列标题语义、不声称已经完成视觉/关系核验。

旧 E3 即使可以找到连续原文，也只生成**待核验的新定位建议**，不改写为自动合格 E1。
旋转表格字符重排、跨列表格重解析、表头继承及合并行含义尚不由本轮代码自动解决，保持未决。

## 4. C 的可执行范围：关系警示筛查

本轮 C 是关系修复前的保守筛查，不是完整语义重抽取。固定规则：

- 原 Schema 关系类型不合法；
- maintained_by 客体为“无需维护”等负向维护要求；
- diagnosed_by / inspected_by 客体仅为铭牌/数据牌，而不是实际检查动作；
- prevented_by 含禁止/否定警告，但没有显式 prevention/avoidance/protection 因果连接；标记目标需复核，不把标记当确定错误；
- prevented_by 的目标只是设备/部件类型；
- 原引用含 if/unless/when/only/except 等条件词，而端点没有相应限定标记；标记限定语义需要显式存储。

这些启发式不保证覆盖所有错误，可能误拦正常记录；应同时报告错误拦截和有源文支持记录的损失。
规则不能读取 v1 的语义标签、匹配结果或记录 ID 来作决定。
