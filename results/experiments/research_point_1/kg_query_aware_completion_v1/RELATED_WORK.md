# 相关方法、实际实现身份与创新性判断

定向核对2026-11-16。没有将查阅等同复现，也不以工作名称证明原创。

| 原始来源 | 相关已有机制 | 本轮处理 |
| --- | --- | --- |
| [SimKGC，ACL 2022](https://aclanthology.org/2022.acl-long.295/) | 文本双塔、对比知识补全 | 实际使用未修改作者模型和logits，本地BGE与采样适配；新任务重新初始化，不沿用见过目标的旧权重 |
| [LAN，AAAI 2019](https://arxiv.org/abs/1811.01399) | 逻辑和神经注意力邻域聚合 | 实际复用上一轮机制适配代码在新划分重训，不冒称作者实现复现 |
| [kNN-KGE原论文](https://arxiv.org/abs/2201.05575)及[作者仓库](https://github.com/zjunlp/KNN-KG) | 根据查询key检索记忆、插值实体概率，帮助稀有实体 | 实际运行相同记忆/概率插值机制的SimKGC适配。作者使用另一种语言模型实体建模，本轮双塔底座与记忆边界不同；故属于机制适配强比较，非全论文逐字复现 |
| [Prob-CBR，EMNLP Findings 2020](https://aclanthology.org/2020.findings-emnlp.427/) | 从相似实体收集关系路径，通过路径统计进行案例推理 | 本轮也是检索相似关系，但没有复现其路径概率模型；有向端点向量迁移不是新案例推理范式，也不伪称Prob-CBR |
| [KGT5-context，2023](https://aclanthology.org/2023.repl4nlp-1.11/) | 在文本补全中加入查询实体邻域信息 | “加上下文”已有先例；本轮扩展到非直接邻接的不确定候选，没有运行T5模型 |
| [KGR3，NAACL 2025](https://arxiv.org/abs/2411.08165) | 检索支持三元组和实体上下文，LLM推理并重排序 | 本轮不使用其LLM推理/微调组件，不能声称复现或优于其完整系统。检索＋文本＋重排组合本身不是原创 |

可研究差异在于：从可追踪但不全可信的初始候选中进行查询有向角色检索，在固定答案目录和严格副本/来源屏蔽下测试非邻接候选的贡献。该差异首先是**问题与评价协议适配**，不是自动成立的新算法。

目前实测只支持简单检索与端点迁移相对部分基线的内部代理收益；新神经残差未优于它，条件文本辨识仍弱，结构丰富样本不足。不能把“查询检索＋角色表示＋小网络”包装为独创，更不能把超出候选池的预测数量等同新增正确知识。该结果适合保留为强基线与机制证据，尚不足冻结为已经有效的RP1唯一核心算法创新。
