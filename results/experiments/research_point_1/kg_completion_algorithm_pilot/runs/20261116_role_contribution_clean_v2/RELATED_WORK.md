# 实现身份、相关机制与创新性边界

2026-11-16。仅查原论文和作者仓库；本表是定向机制核对，不是穷尽查新。未运行的方法不称复现。

| 方法/来源 | 已有核心内容 | 本轮对应关系与边界 |
| --- | --- | --- |
| [SimKGC，ACL 2022原论文](https://aclanthology.org/2022.acl-long.295/) | 对比学习的文本双塔知识补全 | 复用历史适配版的冻结实体/查询表示与检查点，未重训作者全规模模型；不冒称新文本编码方法 |
| [LAN原论文](https://arxiv.org/abs/1811.01399) | 结合逻辑/网络注意力的邻域聚合，用于出现新实体时的表示 | 复用此前保存的同场景LAN适配结果；它不是作者代码逐字复现。关系感知和邻域聚合不是本轮首创 |
| [GraphMask，ICLR 2021原论文](https://openreview.net/pdf?id=WznmQa42ZAx) | 在训练好的图模型上学习可微边掩码，识别可去除边，含稀疏约束 | 本轮也冻结主体学门，不能以此宣称首创。区别尝试在训练源角色扰动的功能margin及绝对门锚定，尚无额外收益证明；未完整复现GraphMask |
| [CFLP，ICML 2022原论文](https://proceedings.mlr.press/v162/zhao22e.html)及[作者代码](https://github.com/DM2-ND/CFLP) | 构造反事实链接作图表示学习的增强数据，联合预测事实与反事实链接 | 本轮是有向多关系邻域slot干预，不是该论文的匹配链接处理；不把冻结模型utility称真实因果效应。未运行完整CFLP |
| [S²DN，AAAI 2025原论文](https://ojs.aaai.org/index.php/AAAI/article/view/33346) | 对归纳知识补全同时建模语义平滑与结构去噪 | 与本轮不确定邻域筛抑目标相近；本轮不加其模型层，只检验原门的显式监督。未复现或宣称超过S²DN |
| [类型引导自监督降噪原论文](https://proceedings.mlr.press/v258/sun25b.html) | 利用类型信息引导自监督去噪 | 类型合法只作为本轮硬边界；负例仍类型合法，因此不是以类型错误充当困难负例。没有把类型约束包装成创新 |

本轮实现身份：**基于旧SimKGC适配底座的自研目标函数原型，非作者方法复现**。主模型结构和原有权重来源均保留；新内容是监督构造、训练干预和梯度控制协议。softplus排序、BCE、标签平滑及门控均属已有技术。

若full不优于BCE-only和shuffled，就不能以“来源角色约束＋干预”这个名称认定有实质算法贡献。本轮正是这种结果。因此，论文中可以如实记录失败和可辨识性分析，但不能把当前原型写成已验证有效的原创知识增强算法。
