# 关系感知可信候选协同补全：已编码的方法定义

本轮模型是冻结SimKGC双塔上的轻量关系邻域残差适配器，代码`code_collab_v1/model.py`，不是重新抽取或改写正式图。文本底座优先复用上轮G2最佳检查点；新结构任务从预训练权重重新训练底座，避免旧训练标签泄漏。

## 表示与可用输入

对查询(h,r,?)，SimKGC输出单位向量q(h,r)，尾实体目录单位向量z(t)。逆向查询(t,r^-1,?)仍预测头实体，但逆向只用于评分，不新增确认关系。基础文本编码器冻结；约10万参数适配器可训练。

每个一跳邻边c=(h,s,u)或(u,s,h)保留有向关系编号s（正/逆各15类）和头尾角色d。候选保留状态、原始ID、来源页和证据合同特征。Schema非法边保留账本，但不作为消息。12维特征包括类型合法、可定位、合同语义支持、保守准入、隔离/拒绝标记、基础身份、重复数/来源族数、条件/否定线索。它们均为程序/原有抽取特征，不是人工真值。

## 计算流程

记关系嵌入a_s、方向嵌入b_d、低维投影Wq/Wn：

```
v_c = tanh(Wn z(u) + a_s + b_d)
e_c = w^T tanh(Wq q(h,r) + a_r + v_c)
g_c = 1                                  （基础训练边）
g_c = sigmoid(MLP([f_c, q·z(u), cos(a_r,a_s), log(1+degree)/3])) （候选）
α = softmax([e_1,...,e_N,e_null])
m = Σ_c α_c g_c v_c
δ = 0.25 * tanh(Wo m) / sqrt(512)
q+ = normalize(q + δ)
score(h,r,t) = q+ · z(t)
```

null项为可学习标量，值消息固定零。Wo不含偏置且初始化为零，因此全部头在epoch0恰好恢复相同文本底座。最大16邻边按基础优先和固定散列截断；截断不使用测试目标或预测分数，不保证包含全部潜在有用候选。报告实际覆盖，不能把全池大小当作每次查询的计算邻居数。

可信门g是**在当前补全任务中的贡献系数**，不能解释为源文事实正确概率。注意力α是相对分配，门g是绝对抑制；两者仍可能不可辨识或共适应，必须通过消融检验是否有额外作用。原文全文没有进入新适配器，使用的是文本端点表示和声明的证据/结构特征，不冒称源文蕴含模型或条件逻辑推理。

## 约束性质及理论边界

对完整机制，0≤g≤1且α在邻居+null上归一化，所以实际邻居总权重Σαg≤1−α_null≤1。若没有有效邻居，或所有候选门趋零且无基础邻居，则m=0、δ=0，精确退回原文本得分；普通仅softmax聚合没有绝对门时会强制在噪声邻居之间分配质量。

逐维tanh和1/sqrt(512)保证||δ||₂≤0.25。q为单位向量时，||q+δ||≥0.75，所以归一化不会除零。三角不等式给出||normalize(q+δ)−q||≤2||δ||≤0.5，因此任一单位尾向量的分数扰动也不超过0.5。该界仅限制数值扰动，不保证排名改善、真实事实正确或诊断安全；有界残差、门控及null记忆均有已有研究基础，不能因推导此界宣称新理论。

## 训练和防自证

用基础训练Claim的正/逆查询作全2150实体softmax交叉熵，温度系数20；同一训练查询的其他已知正例mask，不把未知尾认定为经验证反例。候选只作上下文，不全部生成正例标签；其作用通过基础补全目标反向传播到门和关系聚合参数。

每个训练例输入邻域都移除整事实/证据组、组内同义端点对、同来源页候选；防止把目标或同引句复制作为输入。验证/测试事先全局移除目标组、反向/同义对、重复候选及20字符证据副本，模型输入只接收查询锚点与关系，不接收目标ID或目标源文。候选状态原有自动质量信号仍可能有误，finite blocker也不是全部语义转述无泄漏的数学证明。

## 匹配对照与实现身份

原SimKGC、G2、G3保留旧冷场景结果；新增简单过滤（合法+证据定位）按原SimKGC预算训练。全部适配器共享种子匹配G2冻结特征、基础监督和同预算：full、no_dynamic(g=1)、fixed(原状态权重)、no_relation(聚合器不看关系类型但保留方向，底座仍有关系文本)、no_neighbor(同容量纯文本残差)、no_null、LAN-Text，以及不同规模/质量/合成扰动。

LAN-Text按[原论文](https://arxiv.org/html/1811.01399v2)的关系共现置信P(s⇒r)、冗余比值及神经注意力相加实现；分母下界0.05，沿用同冻结文本、cosine decoder和残差上限。这是明确的机制适配，不是作者TensorFlow/TransE端到端复现。它保留关系查询、逻辑与神经机制，不能用弱均值聚合冒充LAN。普通查询注意力等已有能力也由no_dynamic强对照保留。

[RAA-KGC](https://arxiv.org/html/2504.06129v2)是同关系锚点文本双塔；本轮检查作者代码但没有将向量聚合冒称该作者模型。与其区别是候选证据门与null贡献抑制，而不是声称首次使用文本与关系邻居。与UKGE/FocusE/NAAER等的置信利用也有重叠；只有稳定优于匹配公开适配及相关消融，才可能支持有限领域方法增量，不能自动证明原创性。

## 评价与判定

原213项测试已公开，所有新设计只用训练和验证选择；本轮不把旧测试重新称为未见。新结构测试18项（6项双端基础支持、12项候选辅助支持），验证10项；严格整组排除后重新检查非零度。非零邻居并不意味着存在可推出目标的有效逻辑路径，这一小样本不构成充分独立泛化证据。

固定三种子完整报告MRR、Hits@1/@10和首选Schema合法率；配对按事实组重采样区间，并保留全部负结果。用同一full权重删除候选、删除全部邻域和打乱邻边关系做输入干预，区分确实使用结构与单纯增加参数。所有测试后干预只评价，不训练、不改变模型选择。独立文档核查只评价源文支持，不能与自动标签恢复混成事实准确率。
